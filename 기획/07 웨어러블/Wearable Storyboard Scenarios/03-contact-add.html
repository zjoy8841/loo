③ 연락처 등록 — 거래처 미팅

비즈니스 미팅에서 처음 만난 거래처 담당자의 정보를 글래스가 자동으로 수집·정리한다. 카메라 안면 인식 + 명함 캡처 + 대화 STT를 결합해, 인사 후 미팅 종료 시점에 한 카드로 "저장할까요?" 제안. 사용자는 저장 버튼 한 번으로 마무리.

CUT 1 · 미팅 시작

1. 거래처 사무실에서 첫 미팅. 글래스를 쓴 사용자가 담당자와 악수하며 인사. 글래스는 이미 비즈니스 컨텍스트(캘린더에 "거래처 미팅" 등록)를 인지하고 백그라운드 수집 모드.

5. 저장 버튼 제스처 → 연락처 + 비즈니스 노트에 동기화. 후속 액션으로 "2주 뒤 팔로업 알림" 자동 제안. 글래스가 인맥 관리를 도와줌.

시나리오 메모

  • 컨텍스트 감지 — 캘린더 "거래처 미팅" 이벤트 + 위치 기반. 일반 사적 만남에서는 자동 발동 X (프라이버시).
  • 정보 출처 3종 — ① 안면 인식(사진), ② 명함 OCR(전화·이메일·주소), ③ 대화 STT(직책·소속·맥락). 셋이 교차 검증되어 신뢰도 높은 항목만 카드에 노출.
  • 상대방 동의 — 명함 교환 행위 자체가 정보 공유 동의로 간주. 명함 없이 일방적 안면 캡처만 한 경우 저장 카드 노출 X (법적·윤리적 가드).
  • 팔로업 제안 — 비즈니스 미팅 자동 분류 → 알림 시스템(03 알림)과 연동해 후속 액션 시드 생성.

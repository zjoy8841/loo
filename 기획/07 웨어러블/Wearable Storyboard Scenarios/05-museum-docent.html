⑤ 도슨트 시나리오 — 박물관 학습

박물관을 관람하는 학생이 도슨트 모드를 활성화하면, 글래스가 유물을 자동 인식해 음성 + HUD 카드로 해설한다. 학생은 손을 자유롭게 두고 유물에 집중. 해설은 학습 노트에 자동 정리되고, 보고 싶은 작품을 음성으로 검색하면 가는 길의 추천 작품과 동선까지 묶어서 박물관 내부 네비게이션으로 안내.

"맞아" / 박물관 이름 말하기

1. 박물관에 들어선 학생이 "도슨트 모드 켜줘" → 글래스가 GPS로 박물관 후보를 띄움. 학생이 "맞아"라고 하거나 박물관 이름을 직접 말하면 해당 박물관의 유물 정보·동선 데이터가 로드되며 해설 기능 활성화.

CUT 2 · 백제 유물 해설

🏺 백제 금동대향로

국보 287호 · 6~7세기

충남 부여 능산리 출토

백제 금속공예의 최고 걸작. 뚜껑에 74개 산봉우리 + 5인의 악사 + 봉황 1마리. 도교·불교 사상이 담김.

🔊 음성 해설 중

"백제 금속공예의 정수…"

2. 학생이 백제 금동대향로 앞에 멈춰 응시 → 글래스가 유물을 자동 포커싱·인식. HUD에 상세 카드가 뜨고 동시에 음성으로 해설이 흘러나옴.

CUT 3 · 학습 노트 자동 저장

✓ 학습 노트에 저장됨

백제 금동대향로

사진 · 해설 · 위치 · 시각

관람 후 폰에서 전체 노트 정리

3. 해설이 끝나면 글래스가 유물 사진 + 해설 텍스트 + 위치·시각을 학생의 학습 노트에 자동 저장. 관람 후 폰에서 한 번에 복습 가능.

4. 학생이 음성으로 "모나리자 그림으로 가자"라고 검색 → HUD에 위치·거리 + 가는 길의 추천 작품 5점 + 동선 옵션(추천 12분 / 최단 4분)이 뜨고, 바닥에 AR 화살표·동선 점선이 깔린다. 박물관 내부 네비.

시나리오 메모

  • 트리거 — 음성 명령 "도슨트 모드 켜줘" / 박물관 위치 진입 시 자동 제안 ("도슨트 모드 켤까요?"). 학생 자율 선택.
  • 박물관 선택 (CUT 1) — 모드 활성화 후 GPS·Wi-Fi 비콘으로 박물관 후보를 자동 제안. 학생은 ① "맞아"로 추천 수락 ② 박물관 이름 직접 발화 ③ 후보 리스트에서 음성 선택 중 택. 박물관별 유물 정보·동선·전시 일정 데이터를 그 시점에 로드. 실내 GPS 약한 경우 박물관 입구 비콘·QR 스캔으로 보정.
  • 유물 인식 — 비전 모델 + 박물관 메타데이터(전시 위치·도록). 명패 OCR로 보조. 신뢰도 낮으면 명패 정보만 노출하고 음성 해설은 보류.
  • 해설 콘텐츠 — 박물관 공식 도록·교과 연계·연령대별 깊이 조정. 초·중·고·일반 4 레벨. 마이페이지에서 선택.
  • 학습 노트 자동 저장 — 사진(글래스 캡처) + 해설 텍스트 + GPS·시각 메타. 관람 후 폰에서 한 번에 정리·요약. 시험 대비 퀴즈 자동 생성도 후속 기능 후보.
  • 큐레이션 동선 — "백제 코스"·"근현대 회화"·"불교 미술" 같은 주제별 코스. 박물관 측이 미리 제공한 경로 또는 학생 관심사 기반 AI 추천. AR 화살표로 안내.
  • 자유 검색 + 박물관 네비 (CUT 4) — "○○ 그림으로 가자" 음성으로 특정 작품 즉시 탐색. 위치·거리·도보 시간과 함께 가는 길의 추천 작품 N점(시대·작가·관심사 매칭)을 묶어서 자동 큐레이션. 동선 옵션은 ① 추천 동선(거치며 보기) ② 최단 경로 ③ 접근성 동선(엘리베이터·휠체어) 3종. 바닥 면 AR 화살표 + 추천 작품 위치 마커.
  • 접근성 — 청각 장애 학생: 음성 해설을 자막으로 동시 출력(G-4 자막 모드 연동). 시각 장애: HUD 비활성, TTS 단독 + 점자 보조.
  • 다국어 — 외국인 관람객 대상 자동 번역 해설(설정에서 언어 선택).
  • 박물관 협력 — B2B 모델 후보. 박물관이 공식 도록·동선·이벤트 정보를 제공, 우리가 글래스로 전달. 박물관 입장권 + 도슨트 구독 번들.

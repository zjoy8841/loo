인터랙션 매핑

1
HUD 단독 채널 — 음소거 모드(폰·캘린더 회의 중·시간대 설정) 감지 시 G-1(음성)이 자동으로 G-3(HUD)로 전환. 동일 알림이 채널만 갈아탐.
2
피크 → 미니화 — 첫 3초만 카드(중간 크기). 3초 후 우상단 작은 도트 + "점심" 텍스트로 축소. 시야 방해 최소화.
3
Head tilt up — 시야를 살짝 위로 들면 카드 확장(피크 → 자세히). 일반적인 시선 이동(좌우)으로는 트리거되지 않음. 위쪽 15° 유지 1초가 임계값.
4
끄덕임 (nod) — 카드 확장 상태에서 위아래 끄덕임 = "폰으로 이어보기". 폰이 활성 상태면 즉시 06 결과 상세 열림. 잠금 상태면 알림 배너만 띄움.
5
좌우 흔들기 (shake) — "닫기". 알림은 폰 센터에 그대로 남음(글래스에서 닫아도 사라지지 않음). 회의 끝나고 폰에서 확인 가능.
6
자동 닫힘 (timeout) — 미니화 후 8초 추가 무반응 시 HUD 완전 닫힘. 알림 자체는 폰에 남음. 같은 알림이 30분 안에 다시 노출되지 않음(스누즈 기본).

동작·상태 규칙

·
음소거 감지 우선순위 — ① 캘린더 회의/포커스 모드 ② 폰 무음 ③ 사용자 수동 토글 ④ 환경 소음 분석(보조). 셋 중 하나라도 켜져 있으면 HUD 단독.
·
HUD 위치 — 우측 안쪽 모서리 기본. 사용자가 마이페이지에서 좌/우/상단 중앙 선택 가능. 시선이 자연스럽게 향하는 위치에 배치.
·
HUD 카드 정보 밀도 — 한 번에 최대 5요소(타이틀·메타·아이콘·액션·타임아웃). 더 많은 정보는 폰으로 위임. 손코딩 가능한 마이크로 디스플레이 텍스트 한계 고려.
·
제스처 오인식 — 발표자가 끄덕끄덕하는 회의 환경에서 오트리거 방지. 시선이 HUD 영역(위쪽)에 머문 후 0.5초 안에 끄덕임이 와야 유효. 단순 끄덕임은 무시.
·
접근성 — 제스처 사용이 어려운 사용자: 측면 물리 버튼 1탭 = 확장 / 2탭 = 폰으로 / 길게 = 닫기. 모든 제스처는 폴백 매핑 존재.

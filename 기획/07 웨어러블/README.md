### 두 가지 사업 시나리오 — 기획은 ②를 가정 (2026-05-21 확정)

**① 현 사양 그대로 사용 (제휴 없음)**
- 가능: 폰 TTS·STT 가 BT 오디오 채널로 글래스 스피커/마이크 통과
- 불가: 글래스 카메라·디스플레이·센서 직접 제어, 글래스용 앱 배포
- 결론: "오디오 채널"만 활용. HUD·카메라 시나리오 전부 불가.

**② Seerslab 과 제휴 → 단독 앱 + 연동 글래스 (HUD 포함)**
- 형태 (셋 중 하나):
  - **ODM/맞춤 펌웨어** — 통신 프로토콜·API·펌웨어 수정권 제공받음
  - **B2B 라이선스 + 전용 API** — NDA 하 내부 SDK 제공
  - **공동 개발** — 펌웨어 일부 직접 작성
- 결론: SDK·HUD 둘 다 "있다"고 가정 가능. **이 문서의 시나리오는 ②를 전제**.
- 별도 트랙: 비즈니스 협상·NDA·HUD 탑재 모델 협의 (개발팀 외)

→ **MVP 가능 여부의 선결 조건은 제휴 성사**. `ainoon@seerslab.com` / `070-7702-6800` 으로 사업 측 접촉 필요.

## 🎯 초기 범위 (제휴 + HUD 가정)

### 글래스 (1순위, 아이눈 + 제휴 HUD)

가정한 HUD: 마이크로 디스플레이 또는 도파관, 1~3줄 텍스트 카드, 작은 아이콘, ~640×400 수준, 한 번에 정보 1개. **시각은 보조, 음성이 메인** 원칙.

- **음성 알림 채널** — 03 알림 도착을 글래스 스피커로. 폰 안 꺼내고 이동 중 첫 임팩트 파악.
- **HUD 시각 노출** — 핵심 알림·일정 한 줄을 HUD 카드로. 음성이 어려운 환경(회의·소음) 대안.
- **카메라 컨텍스트** — 12MP 캡처 → 음식·약·문서 인식 → 자동 알람 등록 제안. 음성/HUD 양방향 응답.
- **음성 어시스턴트** — 03 알림 U-04-7 "라이언과 대화"의 음성+HUD 확장 (후보).
- **HUD 자막** — 마이크 캡처 → 실시간 번역/자막을 HUD에. 접근성·외국어 회의.

### 워치 (후순위, 애플워치)

- **알림 + 빠른 응답** — 03 알림 도착을 손목 햅틱으로, 응답 버튼은 워치에서.
- **컴플리케이션** — 워치 페이스에 다음 일정·플랜 진행률.

### 공통 연동 레이어

- 페어링·권한·세션 동기화.
- 어떤 알림을 어느 기기로 라우팅할지 정책 (마이페이지 하위 후보).

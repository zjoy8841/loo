# 07 웨어러블 — 스마트글래스 시나리오 풀

> 2026-05-21 작성. 글래스(아이눈 + 제휴 HUD 가정)에서 가능한 사용 시나리오 전 범위.
> 각 줄은 **시작 → 사용자 행동 → 글래스 반응 → 종료**가 한 줄로 보이도록 작성.
> 이 풀에서 MVP 시나리오를 다시 선별 → `v0.1/` wireframe 갱신.

---

## 1. 알림 도착·확인

1. 출근길 지하철에서 오늘 첫 알림이 글래스 스피커로 TTS 발화되고, 사용자가 "응" 하면 자세히 듣고 "넘겨"로 종료한다.
2. 회의 중 음소거 환경에서 HUD 우상단에 알림 도트가 잠깐 뜨고, head tilt(시선 위)로 카드가 확장되며, 좌우 흔들기로 닫는다.
3. 도서관에서 일정 알림이 HUD로만 오고, 끄덕임 한 번에 폰으로 이어 보내 회의 끝나고 폰에서 확인한다.
4. 자전거 타다가 알림이 오면 "다음에"라고 말해 30분 뒤 다시 받기로 스누즈하고 라이딩을 계속한다.
5. 운전 모드 감지 시 알림은 보류되었다가 정차하면 한꺼번에 음성 요약으로 들려준다.
6. 알림 여러 건이 동시에 도착하면 글래스는 가장 중요한 한 건만 발화하고 나머지는 폰 알림 센터에 쌓아둔다.
7. 특정 장소(예: 마트 근처) 도착 시 위치 트리거 알림이 HUD에 "근처 미션 1건"으로 뜬다.
8. 부재중 전화·메시지가 HUD 상단 핀에 누적되어 있다가 "메시지 읽어줘"로 차례로 들을 수 있다.
9. 음성·HUD 둘 다 끈 상태에서는 안경다리 햅틱 진동만으로 알림이 왔음을 알린다.
10. 같은 알림을 30분 안에 두 번 받지 않도록 글래스에서 닫은 알림은 자동 스누즈된다.
11. 잠금 모드(수면·운전·집중)에 따라 알림 전달 우선순위를 자동 조정한다.

## 2. 카메라·비전 캡처

12. 손에 든 약 봉투를 보면서 "이거 등록"하면 카메라가 캡처하고 비전이 약 이름·복용 시간을 인식해 알람 3건 등록을 제안한다.
13. 식당 메뉴판을 보며 "번역"하면 글자를 인식해 한국어 번역 결과를 HUD에 띄운다.
14. 길에서 만난 사람의 명함을 보면 OCR로 자동 인식해 "연락처 저장"으로 폰 주소록에 추가한다.
15. 책 페이지를 캡처해 폰 노트 앱으로 자동 저장하고 OCR 텍스트까지 같이 보낸다.
16. 영수증을 찍어 가계부 앱으로 자동 분류·전송한다.
17. 운동 자세를 잠깐 캡처해 폼 분석 결과를 HUD에 화살표로 받는다.
18. 마트에서 상품 바코드를 인식해 가격 비교·리뷰 요약을 HUD에 띄운다.
19. 와인 라벨을 찍어 사용자의 와인 로그에 자동 추가하고 비슷한 추천을 받는다.
20. 약 봉투 캡처 시 이미 등록된 약과 성분이 충돌하면 "이거 ○○과 같이 먹으면 안 돼요" 경고가 HUD·음성으로 동시에 뜬다.
21. 잠깐 본 풍경·순간을 "기억해" 한 마디로 사진 캡처 + 위치·시간 메타데이터로 일기에 자동 저장한다.
22. 식재료를 보고 "이거로 뭐 만들지?"라고 물으면 비전 인식 후 레시피를 음성·HUD로 제안한다.

## 3. 음성 어시스턴트·라이언

23. "라이언" 호출어로 음성 모드를 켜고 "내일 회의 몇 시야?"라고 묻고 TTS 응답 + HUD 핵심 카드를 받는다.
24. "오늘 일정"으로 하루 요약 브리핑을 음성으로 듣는다.
25. "다음 1시간"으로 단기 일정·할 일만 음성 안내 받는다.
26. "메모 해줘 우유 사기"로 즉시 노트가 생성된다.
27. "지금 어디?"로 위치 + 다음 일정 + 도착 예상 시각을 음성으로 받는다.
28. "5분 타이머"로 카운트다운이 HUD 우상단에 뜨고 끝나면 햅틱·음성으로 알린다.
29. "주차 위치 기억"으로 GPS + 카메라 한 컷을 저장하고, 나중에 "내 차 어디"로 화살표 안내를 받는다.
30. 음성으로 메시지를 받아쓰고 발송한다 — "○○에게 30분 늦는다고 보내".
31. "방금 들은 거 요약"으로 직전 5분 환경 오디오를 STT 처리해 요약본을 노트로 받는다.
32. "이게 뭐야?" 음성과 함께 시야 대상물을 인식하게 한다 (비전 + LLM 결합).

## 4. 자막·번역·청각 보조

33. 외국인과 대화 시 "자막"으로 실시간 자막 모드를 켜 원문 + 번역을 HUD 하단 wide 카드로 본다.
34. 청각 보조 모드(한국어→한국어 자막)로 회의 발화를 놓치지 않고 캐치한다.
35. 영어 강의를 들으며 자막 + 핵심 키워드 노트가 자동으로 폰에 적재된다.
36. 해외 여행에서 식당 직원과 대화 자막 모드로 주문하고, 종료 후 대화 기록을 폰에 저장 옵션으로 받는다.
37. 사인·간판·표지판을 보면 사용자 트리거 없이도 자동 번역이 HUD에 잠깐 뜨고 사라진다 (passive 모드).
38. 회의 참석자가 여러 명이면 화자 이름 라벨링이 자막 옆에 표시된다.

## 5. 일정·플랜·정보 HUD

39. 다음 일정까지 남은 시간이 HUD 우상단에 작은 도트로 항상 떠 있다 (always-on 미니 모드).
40. 플랜 진행률(예: "공부 4/7")이 HUD에 작게 떠 있고, 시선을 올리면 상세 카드로 확장된다.
41. 미팅 시작 5분 전 HUD에 "○○님과 미팅 · ○○ 카페" 카드 + 길찾기 단축 버튼이 뜬다.
42. 운동 플랜 진행 중 다음 세트·휴식 타이머가 HUD에 박혀 있어 폰을 안 봐도 된다.
43. 회의 시작과 동시에 참석자 이름·직책·최근 메모 카드가 HUD에 잠깐 뜨고 사라진다.
44. "오늘 컨디션 점수"가 HUD에 잠깐 표시되었다가 자동 닫힌다.
45. "내일 날씨"가 잠자기 전 자동으로 HUD에 한 줄 뜬다.

## 6. 길찾기·이동·내비

46. "○○까지 길찾기"로 HUD에 화살표 + 다음 동작 + ETA가 뜨고 좌회전 직전에 햅틱 신호가 온다.
47. 도보 내비게이션 중 다음 코너만 HUD에 화살표로 노출, 지도는 폰에만 둔다.
48. 자전거·러닝 중 페이스·심박·다음 코너만 HUD 라이트 모드.
49. 대중교통 환승 시 HUD 상단 핀에 "다음 정거장: ○○역, 도보 3분"이 떠 있다.
50. 택시·우버 호출 후 차량 도착까지 카운트다운이 HUD에 떠 있고, 차량 도착 시 햅틱으로 알린다.
51. 모르는 곳에서 "여기 어디?"로 음성으로 현재 위치·근처 랜드마크를 받는다.

## 7. 운동·헬스·웰빙

52. 러닝 중 심박·페이스·거리만 HUD 라이트 모드로 보고, 페이스가 흔들리면 "페이스 빨라요" 음성 코칭을 받는다.
53. 헬스장에서 세트 카운트가 카메라·자이로로 자동 카운트되고, 휴식 타이머가 HUD에 뜬다.
54. 요가·스트레칭 중 자세를 카메라로 분석 받아 HUD에 교정 화살표가 뜬다.
55. 일일 활동 목표 진행률이 HUD 도트로 항상 노출된다.
56. 명상 모드에서 호흡 가이드를 음성 + HUD 작은 원 호흡 시각화로 받는다.
57. 수분 섭취 알림이 2시간마다 HUD에 잠깐 뜬다.
58. 자세 교정 — 장시간 거북목·구부정한 자세 감지 시 햅틱 + "자세 펴세요" 음성 코칭.

## 8. 결제·쇼핑

59. 카페 카운터에서 "결제"로 NFC·QR 트리거를 켜고 HUD에 결제 카드 선택을 노출한다.
60. 쇼핑 리스트가 마트 입장 시 HUD에 자동 노출되고, 카트에 담을 때마다 비전 인식으로 자동 체크된다.
61. 가격표를 보면 "내 예산 대비 ○○%" 메타가 HUD에 잠깐 뜬다.
62. 영수증을 찍어 가계부 분류 + 환급·할인 가능 여부를 음성으로 받는다.
63. 매장에서 본 상품을 "위시리스트에 담아"로 폰 위시리스트에 저장한다.

## 9. 통화·메시지·미디어

64. 인입 전화가 HUD에 발신자 이름·사진으로 뜨고, 끄덕임 = 수락 / 흔들기 = 거절로 응답한다.
65. 메시지가 도착하면 음성으로 들려주고 사용자가 음성으로 답장을 받아쓰게 한다.
66. 음악 재생 중 곡명·다음 곡이 HUD에, 좌우 끄덕임으로 다음/이전 곡 전환한다.
67. 팟캐스트 듣다가 "북마크"로 현재 시점을 저장하고, 나중에 폰에서 그 지점부터 재생한다.
68. 영상 통화 중 상대 얼굴은 폰 화면, 글래스에는 자막·감정 인디케이터만 띄운다.

## 10. 회의·업무

69. 회의 시작과 함께 "회의 모드"로 자막 + 녹음 + 요약이 자동으로 켜지고, 종료 후 회의록이 폰에 자동 정리된다.
70. 발표 중 HUD에 다음 슬라이드의 핵심 키워드만 잠깐 띄워 커닝페이퍼처럼 쓴다.
71. 협업 메신저에서 본인 멘션이 오면 HUD에 핀이 뜨고 음성으로 답장한다.
72. 출장 중 호텔·티켓·일정이 HUD 핀에 누적되어 있고, 입실·체크인 시점에 자동 노출된다.
73. 회의 참석자가 새로 들어오면 얼굴 인식으로 "○○ 팀 ○○님"이 HUD에 1초 뜨고 사라진다.

## 11. 학습·집중·독서

74. 책을 읽다가 모르는 단어에 시선을 두고 "단어"라고 하면 즉시 사전 정의가 HUD에 뜬다.
75. 집중 모드(포모도로)의 진행률이 HUD 도트로 항상 노출된다.
76. 강의를 들으며 자동으로 핵심 키워드가 노트로 적재되고 끝나고 요약을 받는다.
77. 외국어 책을 읽으며 한 문장씩 번역을 HUD에 받는다.
78. 학습 플래너 진행률 + 다음 학습 블록까지 남은 시간이 HUD에 떠 있다.

## 12. 가족·관계·사회

79. 친구·동료를 만나면 HUD에 "마지막으로 본 날 · 최근 대화 주제" 카드가 잠깐 뜬다(개인 CRM).
80. 명함 교환 후 자동 연락처 저장 + LinkedIn·소셜 연결.
81. 가족 위치 공유가 활성화돼 있으면 가족이 새 장소(집·학교·회사)에 도착할 때 HUD에 도착 핀이 뜬다.
82. 기념일이 다가오면 며칠 전 HUD에 카드 + 선물·이벤트 제안.

## 13. 사진·기록·일기

83. "기억해" 한 마디로 시야 캡처 + 위치·시간 메타데이터로 일기에 자동 적재된다.
84. 자동 하이라이트 — 하루 일과 중 글래스가 의미 있는 순간을 추정 캡처해 저녁에 폰에서 정리한다.
85. 음성 일기를 즉석에서 받아쓰게 한다 — "오늘 ○○했고 기분은 ○○"이라고 말하면 노트로 저장.
86. 여행 중 "지금 풍경" 한 마디로 사진 + 짧은 음성 메모를 묶어서 저장.

## 14. 안전·비상

87. "도와줘" 음성 트리거로 위치·심박·카메라 스냅이 비상 연락처와 응급실에 자동 전송된다.
88. 낙상 감지 시 30초 카운트다운 후 자동으로 119·가족에 통보된다.
89. 자전거 헬멧 충격 감지 → 자동 응급 절차.
90. 야간 보행 시 후방 차량 접근을 카메라가 감지해 HUD에 경고를 띄운다.
91. 운전 중 졸음 감지 — 눈 깜빡임·시선 패턴으로 HUD에 경고 + 음성 알람.

## 15. 운전·자전거 등 이동 중 안전 모드

92. 운전 모드 자동 감지 시 글래스는 read-only로 전환되어 자막·복잡한 HUD는 차단되고 길찾기 안전 정보만 남는다.
93. 운전 중 길찾기 보조 — 다음 좌/우회전이 HUD 화살표 + 음성으로만, 시선을 끌지 않게.
94. 자전거 모드에서 ETA·심박·속도만, 모든 알림은 음성으로만.

## 16. 페어링·설정·기기 상태

95. 처음 글래스를 폰에 연결할 때 폰 앱이 페어링 가이드를 띄우고 글래스는 첫 환영 멘트를 음성으로 한다.
96. 배터리 20% 이하에서 HUD에 작게 "배터리 1시간 남음" 알림 + 음성으로 한 번 안내.
97. 글래스 분실 시 폰에서 "찾기" → 글래스에서 음성·HUD 신호를 발신한다.
98. 마이크·카메라·위치 권한은 폰에서 요청·관리하고, 글래스는 사용 중 작은 인디케이터(녹색 도트)로만 표시한다.
99. 사용자 선호 채널(음성 vs HUD)을 시간대·환경별로 자동 학습·전환한다 (예: 출근 = 음성 / 회의 = HUD).
100. "오늘 글래스 활동" 요약을 저녁에 폰에서 받아본다 (사용 시간·발화 횟수·캡처 수).
101. 마이페이지에서 알림 라우팅 정책을 시간대·장소·앱별로 세팅한다 (예: 22~07시 = 진동만).
102. 글래스 펌웨어 업데이트는 폰 앱에서 무선으로 받고, 업데이트 중에는 음성으로 진행 상황을 안내한다.

## 17. 접근성

103. 시각 보조 사용자 — TTS 단독 모드. HUD는 비활성, 모든 정보는 음성으로.

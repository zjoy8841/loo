인터랙션 매핑 · U-15-7

1
카테고리 칩 — "추천"이 기본 활성. 카테고리 선택 시 즉시 필터링. 헤더 검색(search)으로 키워드 검색.
"추천" = 사용자 코호트(성별·생년월일) + 활동 학습 가중치 합산 ranking.
2
뉴스 리스트 — 카드: 카테고리 라벨 + 제목 + 요약 + 출처 + 시각 + 썸네일. "추천" 라벨은 검정 강조(news-tag.rec).
탭 → U-15-8 뉴스 상세 + [읽음] 로그 → 활동 학습(다음 추천 가중치).
무한 스크롤 (페이지네이션).

알고리즘: rank = base + coh_bonus(코호트) + interest_weight(사용자 학습) + recency_decay.
데이터: 뉴스 API (또는 시연용 mock 30-50건). 카테고리·태그·요약은 LLM 후처리(요약은 50자).
접근성: 리스트 = role="feed", 카드 = role="article".
코드 위치(예정): web/src/app/user/curation/news/page.tsx

에러 페이지 v0.1 — wireframe + 코드별 변형

HTTP 에러 코드를 그대로 노출하면서 위트 있는 카피로 사용자를 안내하는 단일 템플릿. 코드별로 헤드라인·설명·CTA만 바뀌고 골격은 동일.

v0.1 스코프

  • 1 템플릿 · N 코드 — 같은 화면 구조에서 헤드라인·설명·CTA 카피만 코드별로 교체. 코드 자체를 큰 숫자로 노출하는 게 핵심 의도.
  • 위트 카피 — "서버가 점심 먹으러 갔어요"(503), "전 주전자라서요"(418) 등 친근한 한 줄 + 정확한 HTTP 영문 라벨 병기.
  • 라이언 마스코트 활용 — mount 시 tilt(갸우뚱) 한 번 트리거 → 어리둥절함 표현. 마스코트 탭 시 bounce.
  • 그레이스케일 — 시멘틱 컬러 X. 강조는 굵기·보더·코드 숫자 크기로.
  • 대표 화면 1장 (404) + 코드별 변형 비교 5장 (403 · 401 · 500 · 503 · 418).
  • v0.1 범위 외 — 라우트 설계(Next.js not-found.tsx/error.tsx 매핑), 다국어, 에러 원인 자동 진단, 운영팀 알림 전송 로직. 디자인 컨펌 후 개발 라운드에서 진행.

디자인 원칙

  • 코드 우선 노출 — 화면 진입 후 0.5초 안에 "내가 무슨 에러를 만났는지" 인식 가능해야 함. 코드 숫자가 시각적 anchor.
  • HTTP 표준 영문 병기 — 코드 옆에 NOT FOUND, SERVICE UNAVAILABLE 등 표준 라벨. 검색·디버깅 단서.
  • 위트 ≠ 무책임 — 농담은 헤드라인 한 줄까지. 설명·hint는 정중하게. 사용자가 "내 잘못인가?" 헷갈리지 않게 카탈로그 표 책임 컬럼처럼 사용자/서비스 측 중 누구 문제인지 분명히.
  • CTA는 막다른 길 회피 — 홈으로 / 이전 페이지 / 다시 시도 중 항상 최소 1개. 모든 변형에 "홈으로" 기본 포함.
  • 접근성 — 코드 숫자는 aria-label="에러 코드 404". CTA는 키보드 포커스 가능. 마스코트는 aria-hidden (장식).

주요 인터랙션 매핑

1
× 닫기 (옵션)
모달/오버레이 형태로 호출된 에러일 때만 노출. 풀스크린 에러 페이지(라우트 진입형)에선 숨김. 닫으면 router.back().
2
라이언 마스코트 — 갸우뚱 (tilt)
mount 시 tilt 1회 자동 트리거 → 어리둥절함 표현. 탭 시 bounce. aria-hidden="true" (장식). prefers-reduced-motion이면 정적 표시. 마스코트 컴포넌트 = RyanMascot (web/src/components/RyanMascot.tsx).
3
코드 숫자 — 메인 시각 anchor
120px 큰 숫자 + 아래 HTTP 표준 영문 라벨 (NOT FOUND). aria-label="에러 코드 404". 코드 자체가 검색·디버깅 단서이므로 화면 진입 후 0.5초 안에 인식되게 우선 배치.
4
CTA — 막다른 길 회피
모든 에러 변형에 "홈으로" 기본 포함. 코드별로 보조 CTA만 교체: 404·403 = "이전 페이지" / 500·503·504 = "다시 시도" / 401 = "로그인". 키보드 포커스 가능, Enter/Space 동작.
5
ERR-ID · 타임스탬프 (운영 대응용)
500번대일 때 필수. 사용자가 운영팀에 문의할 때 이 ID로 로그 조회. 4xx는 옵션. 폰트 작게, 회색으로. 길게 누르면 클립보드 복사 (v0.2).

※ 색·폰트·픽셀·radius·motion·WCAG 등 시각 사양은 디자인 가이드 참조. 본 wireframe은 인터랙션·동작 매핑 목적.

※ 라우트 매핑(Next.js not-found.tsx/error.tsx/global-error.tsx), 다국어, 에러 자동 진단은 v0.1 범위 외 — 개발 라운드에서 결정.

※ 같은 골격으로 다른 코드는 어떻게 보이는지 → 아래 코드별 변형 비교 섹션.

후속 정책 (개발 라운드 추천안)

  • Next.js 라우트 매핑 — app/not-found.tsx(404) · app/error.tsx(500 런타임) · app/global-error.tsx(root). 카탈로그를 props로 받는 <ErrorScreen code={...}/> 단일 컴포넌트.
  • 운영 대응 — 500번대는 ERR-ID(uuid 짧은 6자리) 생성 + 서버 로그에 동일 ID 기록 → 사용자 문의 시 추적 가능. 4xx는 ID 미생성.
  • 다국어 — error.404.title · error.404.description 형태 i18n 키. 카피 카탈로그가 원본.
  • 모션 — RyanMascot mount 시 tilt 1회 (description §10 prefers-reduced-motion이면 skip). 코드 숫자 fade-in 200ms.
  • 모달 모드 — 결제·예약 중간 실패는 풀스크린 라우트 대신 BottomSheet에 같은 ErrorScreen 임베드 (× 닫기 노출). U-05 공통 패턴 §4 결제 실패와 정합 검토.

주요 인터랙션 매핑

1
햄버거 → 사이드 패널
동일 컴포넌트 — active와 같음. 메뉴 항목 v0.1 범위 외. active 참조.
2
종 (배지 없음)
idle 상태 = 미확인 알림 count = 0이라 점 숨김. 새 알림 도착 시 → 점 활성 + 본 화면이 active 화면(01)으로 전환. transition 시퀀스는 v0.2.
3
idle 본문 = 미니멀
Hero Decision Card 없음. 시점 인사 + 마스코트 + 페르소나 칩만. 라이언이 능동 push하지 않는 평소 상태 — 사용자가 채팅·음성으로 먼저 말 걸어야 추천 시작. 결과는 본 화면 Hero 영역으로 갱신 (이후 active와 동일 구조 카드).
4
라이언 마스코트 (선택)
RyanMascot 컴포넌트 (개발/web/src/components/RyanMascot.tsx). idle 시 breathe + blink. 사용자가 채팅·음성 입력 시 tilt 발동. v0.1 wireframe은 placeholder만 — 마스코트 실제 노출 여부는 디자인 단계.
5
페르소나 칩 (선택)
회원가입 7단계 입력값 기반 1~2개 노출. "내가 누구인지 라이언이 알고 있다" 신호. v0.1은 표시만, 탭 인터랙션 없음. v0.2에서 탭 시 마이페이지로 보낼지 결정.
6
채팅 입력바 (메인 진입점)
idle 메인의 주 인터랙션. 좌측부터: + 첨부 · 텍스트 · 마이크 · ↑ 전송.
· + 첨부 = 시트 [사진·파일·카메라]. 음식·영수증 사진 라이언 분석 진입. 시트 자체는 v0.2.
· 텍스트 = 라이언 응답 카드가 Hero 영역에 생성 (이후 active와 같은 구조)
· 마이크 = 음성 풀스크린 /user/voice (U-13)
active와 동일 컴포넌트.
7
빠른 액션 칩 (idle 한정)
"뭐 도와드릴까요?" 옆 비어 있는 상태를 채우는 발판. 자주 묻는 4~6개 (점심 추천·일정·날씨·예약 내역 등) 가로 스크롤. 탭 시 채팅 입력바에 자동 입력 + 라이언 응답. active 화면에는 없음 — 이미 추천 카드가 채워져 있으므로.

※ 색·폰트·픽셀·radius·motion·WCAG 등 시각 사양은 디자인 가이드 참조. 본 wireframe은 인터랙션·동작 매핑 목적.

※ 본 화면은 idle (알림 없는 평소 메인). 알림 인터럽트 도착 시 = 01-home-lunch-active.html. 두 화면은 같은 URL /user/home의 두 상태.

※ idle ↔ active 전환 트리거 = 신규 알림 도착 push. 사용자가 메인에 있는 상태에서 알림 받으면 어떻게 표시할지(Hero 영역 자동 갱신 / 토스트 / 모달) 미정 — v0.2.

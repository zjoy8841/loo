메인 (U-03) v0.1 — wireframe + 시점 매트릭스

기존 회원가입·알림·결제 기획과 동선이 맞물리는 메인 화면 골격. 점심 시점 1장으로 시작, 시점 6개의 hero/grid 콘텐츠는 매트릭스로 정의.

v0.1 스코프

  • 점심 시점 2장 (active + idle) — 같은 URL /user/home의 두 상태. active = 알림 인터럽트 도착 / idle = 알림 없는 평소.
  • active: Hero에 알림 콘텐츠가 결정 카드로 표시 + 결제 CTA. 점심·결제 추천 알림 예시.
  • idle: Hero 없음, 미니멀. 인사 + 마스코트 placeholder + 페르소나 칩 + 채팅 입력바 + 빠른 액션 칩.
  • 다른 시점 (아침/오전/오후/저녁/야간)은 동일 active/idle 골격 위에서 콘텐츠만 바뀜 → 시점 매트릭스 참조.
  • 회원가입 v0.2 패턴 그대로 — Phone 420 + Caption 320, ①~⑧ 마커, Critical 인터랙션 8개.
  • 기존 기획 동선 정합 — 결제 진입(④) = U-05 description §4-1 일치 / 종(①) = U-04 알림 / 아바타(②) = U-12 마이페이지.
  • v0.1 범위 외 — Splash 후 첫 진입 환영 화면 / 시점 자동 전환 로직 / 사이드 패널 메뉴 항목 확정 / 디테일 그리드 탭 인터랙션 (display only) / 채팅 입력 결과의 카드 갱신 시퀀스.
  • 구조 결정 — 하단 nav 5칸 폐기. 상단 햄버거 → 사이드 패널(좌측 모달) + 하단 채팅 입력바(ChatGPT 메인 스타일). 메뉴 추가/변경 시 메인 화면 영향 없음.

미결 (v0.2 라운드)

  • 시점 자동 전환 로직 — 클라이언트 시간 기반인지 서버 hint인지 (유저플로우 §8-1 미결)
  • "다른 추천" 동작 — v1 카드 회전 vs v2 대화 화면 진입 (유저플로우 §8-3 미결)
  • 사이드 패널 메뉴 항목 확정 — 홈/알림/마이페이지/시점 시나리오/결제 내역/지도/설정/로그아웃 등 후보. IA 별도 작업 필요
  • 채팅 입력바 결과 시퀀스 — 라이언 응답을 (a) Hero 카드 자동 갱신 (b) 대화 로그 시트 (c) /user/voice 전환 중 어느 패턴? 알림·시나리오와 함께 정의 필요
  • 다른 시점 5장 그리기 필요 여부 — 골격 동일이라 매트릭스만으로 충분한가, 아니면 저녁/야간 등 정서 톤 다른 시점은 별도 wireframe 필요한가
  • Hero Decision Card 영역에 라이언 마스코트 노출 여부 — 라이언 v1(blink/breathe/bounce/tilt) 통합 위치 결정
  • 오늘의 한 줄 ↔ 인사이트 ↔ 일정 알림 분리 정책 — 알림 description과 함께 정의 필요
  • Splash → 회원가입 완료 → 메인 첫 진입 환영 화면 — 화면 IA v2 §4 마지막 줄에 "강화" 표현만 있고 별도 정의 없음

※ 본 wireframe은 인터랙션·동작 매핑 목적. 색·폰트·픽셀·radius·motion·WCAG는 디자인 가이드(v.7 / v.8 / v.9) 참조.
※ 점심 시점 컬러 시안은 이미 v6.10 best (디자인/추가 시안/메인_iOS_HIG_v6/) 등 11장 있음 — 본 wireframe은 그것과 별개의 동작 매핑 도면.
※ 노션 description (U-03)은 본 wireframe 확정 후 작성 예정.

주요 인터랙션 매핑

1
햄버거 → 사이드 패널 (좌측 슬라이드 모달)
메뉴 항목은 v0.1 범위 외 (미정) — 메뉴 추가/변경 시 메인 화면 영향 없도록 분리한 게 핵심 의도.
placeholder 후보: 홈 · 알림 · 마이페이지 · 시점 시나리오(아침/점심/저녁) · 결제·예약 내역 · 맛집 지도 · 설정 · 로그아웃. role="dialog" aria-modal="true" + 외부 클릭/Esc 닫기 + focus trap.
2
종 → 알림 센터
router.push('/user/notifications') → U-04 알림. 배지는 미확인 알림 count > 0일 때만. 0이면 점 숨김. 마이페이지 진입은 사이드 패널 항목으로 이전.
3
Hero Decision Card (active 상태)
본 화면 = active 메인 — 사용자가 메인 보던 중 알림 인터럽트 도착. Hero에 그 알림 콘텐츠가 결정 카드로 표시됨. 점심 시점·결제 추천 알림 예시. 알림 종류에 따라 옷·일정·취침 등 다른 콘텐츠.
알림 없는 평소 메인은 02-home-lunch-idle.html. 앱 종료 후 알림 탭해서 들어온 화면은 알림 도메인(U-04) wireframe v0.3.
4
"예약하고 결제" → 결제 진입
router.push('/user/lunch/payment?menuId=&merchantId=&source=home') → U-05-1 메뉴 상세. 결제 description §4-1 진입 경로 1번 일치. 라이언 컨텍스트 payload 전달.
5
"다른 추천" — 카드 회전
v1: 같은 카드 영역에서 추천 2~3개를 회전 (별 화면 X). v2: /user/lunch 대화 화면 진입 옵션.
v1 회전 시 fade + skeleton. 추천 0개 폴백: "잠시 후 다시 시도".
6
디테일 그리드 3 카드
시점별 콘텐츠 다름 (index.html 시점 매트릭스 참조). 탭 시: RESTAURANT → 가맹점 상세 / NUTRITION → 페르소나 상세 / NEARBY → /user/map. v1 점심: 탭 X (display only).
7
인사이트 한 줄
다가오는 일정·페르소나 속보 1건. 탭 시 해당 시점 화면 또는 대화로 진입. v1: display only. 0건이면 영역 자체 숨김.
8
채팅 입력바 (ChatGPT 메인 스타일)
좌측부터: + 첨부 · "라이언에게 말 걸기" 텍스트 · 마이크 · ↑ 전송.
· + 첨부 = 시트 펼침 [사진·파일·카메라]. 음식 사진(영양 분석)·영수증·식단표 등. 시트 화면 자체는 v0.2.
· 텍스트 = 라이언 응답을 Hero/Grid 카드로 갱신
· 마이크 = 음성 풀스크린 /user/voice (U-13) 진입
· ↑ 전송 = 빠른 액션 실행. 채팅 대화 로그는 메인에 노출 X (라이언 답변은 카드 형태로). 기획서 v5 §1 "음성+네이티브UI+텍스트 fallback / 채팅 인터페이스는 기본 포맷 X" 정합.

※ 색·폰트·픽셀·radius·motion·WCAG 등 시각 사양은 디자인 가이드 참조. 본 wireframe은 인터랙션·동작 매핑 목적.

※ 시점 6개(아침·오전·점심·오후·저녁·야간)의 hero/grid 콘텐츠 매트릭스는 인덱스 참조. 골격은 동일.

※ 결제 진입은 결제 description §4-1과 일치. 알림 도착지·마이페이지 진입점도 화면 IA·결제 description 정합.

※ 하단 nav 5칸은 v0.1에서 제거 — 메뉴 항목 미정 상태에서 nav를 박으면 추가될 때마다 메인 수정 필요. 햄버거 + 사이드 패널 구조로 메뉴 자유도 확보.

※ 본 화면은 active (알림 인터럽트 도착 메인). 알림 없는 평소 메인 = 02-home-lunch-idle.html. 메인 보던 중 알림 도착 시퀀스(transition·애니메이션·자동 진입 여부)는 v0.2 라운드.

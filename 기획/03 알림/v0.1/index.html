일정 알림 앱 5종 분석

"일정 알림"으로 유명한 앱 5개를 골라 각 앱의 핵심 장점을 정리하고, 그 장점이 위 화면 어디에 반영됐는지 매핑했습니다.

앱 핵심 장점 (상세) 본 초안에 반영한 곳
Structured
비주얼 데이플래너		 하루를 시간 레일 타임라인 하나로 시각화 — 지난·지금·예정이 한눈에. 타임라인 위에서 바로 드래그로 시간 이동, 서브태스크 인라인 체크. 놓친 항목을 자동 재배치하는 Replan. 알림이 "할 일 목록"이 아니라 "오늘의 흐름"으로 보이게 만드는 게 핵심. 01 타임라인의 시간 레일 + 지난/지금/예정 3상태 구조. 카드가 시각 순서대로 흐름을 그림.
TickTick
올인원 태스크		 다중 리마인더(한 항목에 최대 5개 알림). Effective/Constant Reminder — 완료를 누를 때까지 계속 다시 울리고, 시스템 알람처럼 방해 금지·수면 모드에서도 발화. 알림 바에서 바로 스누즈·완료·집중 시작. 반복 규칙 자동 생성. 02의 다중 리마인더 행 + 끈질긴 알림 토글. 03의 "중요 알림은 방해금지 무시" 옵션. 01 카드의 즉시 스누즈/완료.
Todoist
자연어 입력		 업계 최고 수준의 자연어 파서 — "매주 금요일 오후 5시 주간보고"를 한 줄로 치면 날짜·시간·반복·라벨까지 즉시 인식. "매월 마지막 금요일" 같은 복잡 반복도 처리. 입력 마찰이 거의 0. 02 상단의 빠른 입력(자연어) 박스 + 파싱 칩. 한 줄 입력 → 아래 폼 자동 채움.
Due
끈질긴 리마인더		 절대 놓치지 않게 하는 데 특화 — Auto-Snooze가 완료할 때까지 짧은 간격(조절 가능)으로 끈질기게 재알림. 자주 쓰는 시간(10분·1시간 뒤)을 프리셋 버튼으로 즉시 설정. "무심코 닫고 잊어버리는" 문제를 정면으로 해결. 02의 끈질긴 알림 재알림 간격 설정 + 01 카드 스누즈 프리셋 시트. 03의 기본 알림 강도 기본값.
Google Calendar
일정 알림 표준		 일정 알림의 사실상 표준 — 이벤트별 다중 알림(정시·10분 전·1일 전), 카테고리(캘린더)별 기본 알림 설정, 종일 일정 별도 알림 규칙. 사용자가 캘린더별로 알림 정책을 한 번만 정해두면 일관되게 적용. 03의 카테고리별 on/off + 기본 리마인더(생성 시 자동 적용). 02의 정시 + 리드타임 리마인더 모델.

장점 → 파생 화면 구성 근거

01 타임라인 — Structured의 "하루를 흐름으로 보여주는 시간 레일"을 메인 구조로. 여기에 TickTick·Due의 "카드에서 즉시 스누즈/완료"를 얹어, 보는 화면이 곧 처리하는 화면이 되게 함.

02 생성·편집 폼 (별도 화면) — Todoist 자연어 입력으로 진입 마찰을 없애고, TickTick 다중 리마인더 + Due 끈질김으로 "절대 안 놓치는" 알림을 만들 수 있게 함. 요청 항목 2(알림 CRUD)를 이 화면이 담당.

03 알림 설정 (별도 화면) — Google Calendar의 "카테고리별 기본 알림 정책"과 Things식 정돈된 카테고리 목록을 합침. TickTick의 방해금지 무시 옵션, Due의 끈질김 기본값까지 한 곳에서. 요청 항목 1(설정 이동 링크)의 도착지.

추가 검토 후보: 알림 도착 시 풀스크린/배너 + 스누즈 프리셋 인터랙션(Due), 메인 알림 센터(전 유형 통합 — 별도 description U-04 본체).

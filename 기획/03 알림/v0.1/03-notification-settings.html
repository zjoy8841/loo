인터랙션 매핑

1
카테고리 토글 — 5종 on/off. 끄면 해당 유형 알림은 발화·수신 안 됨(02 생성 폼의 카테고리와 연동). (Things식 정돈된 카테고리)
2
일정 알림 관리 진입 — "내 일정 알림 전체" 탭 → 01 타임라인(= CRUD 허브). 개수 뱃지로 현황 표시.
3
기본 리마인더 — 새 일정 알림 생성 시 02 폼에 자동 적용될 기본 리마인더 세트. 탭 → 다중 선택 시트. (Google Calendar 기본 알림)
4
기본 알림 강도 — 1회 / 끈질김 + 재알림 간격(1·5·10분). 신규 생성 기본값. (Due 끈질김)
5
방해 금지 시간 — 시작·종료 시각. 이 시간대 알림은 소리·진동 없이 센터에 적립.
6
중요 알림 무시 옵션 — 켜면 "끈질긴 알림"은 방해 금지에도 발화(시스템 알람처럼). (TickTick Constant Reminder)
7
보관 기간 — 7·30·90일. 지난 알림 자동 정리. 기본 30일.

동작·상태 규칙

·
이 화면 진입점: 01 타임라인 우상단 톱니 / 메인 알림 센터 우상단.
·
모든 토글은 즉시 저장(별도 저장 버튼 없음). 변경 시 aria-live로 "켜짐/꺼짐" 발성.
·
각 상세 행(리마인더·강도·시간·보관)은 바텀시트로 값 선택. 시트 사양은 별도 화면으로 분리 가능.
·
접근성: 리스트 행은 role="switch"(토글) 또는 button(상세 진입). 카테고리 토글 라벨에 설명 텍스트 aria-describedby 연결.

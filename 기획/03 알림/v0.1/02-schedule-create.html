인터랙션 매핑

1
빠른 입력 (자연어) — 한 줄 입력 → 반복·시간·리마인더를 파싱해 아래 항목 자동 채움 + 파싱 칩 표시. 인식 실패 토큰은 무시하고 수동 입력 유도. (Todoist 강점)
2
파싱 칩 — 인식 결과를 칩으로 미리 보여줘 사용자가 확인. 칩 탭 → 해당 항목으로 스크롤·수정.
3
날짜·시간 — 탭 → 네이티브 피커 시트. 자연어로 채워졌어도 직접 덮어쓰기 가능.
4
반복 — 칩 단일 선택. "맞춤" → 상세 반복 규칙 시트(요일·간격·종료일).
5
다중 리마인더 — 정시 외 N개 추가(10분·1시간·1일 전 등). 각 행 X로 제거. (TickTick·Google Calendar 강점)
6
알림 강도 — "1회" vs "끈질긴 알림". 끈질김 선택 시 재알림 간격 노출. 완료 누를 때까지 반복. (Due·TickTick Effective Reminder 강점)
7
카테고리 — 일정/미션/건강/맞춤. 03 알림 설정의 카테고리 토글과 연동(꺼진 카테고리는 발화 안 됨).
8
저장 / 삭제 — 저장 활성 조건: 제목 1자+ AND 날짜·시간 유효. 편집 모드에서만 삭제 버튼 노출. 삭제 → 확인 다이얼로그.

동작·상태 규칙

·
신규/편집 공용 화면. 신규 = 헤더 "새 일정 알림", 편집 = "일정 알림 편집" + 삭제 버튼 노출 + 기존 값 프리필.
·
저장 → 01 타임라인으로 복귀, 해당 시각에 카드 삽입(반복이면 다음 회차 기준).
·
접근성: 각 필드 label htmlFor 연결. 자연어 파싱 결과는 aria-live="polite"로 발성. 강도 토글은 라디오 그룹.
·
"끈질긴 알림"이 방해 금지 시간과 겹칠 때 동작은 03 설정의 "중요 알림 방해금지 무시" 값에 따름.

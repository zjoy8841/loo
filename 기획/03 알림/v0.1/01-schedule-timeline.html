인터랙션 매핑

1
설정 진입 링크 — 우상단 톱니. 탭 → 03 알림 설정. (요청 항목 1: 알림 설정 화면 이동 링크)
2
방금 울림 슬롯 — 최근 발화된(아직 미처리) 알림을 최상단에 정보색 카드로 고정. 처리 전까지 타임라인 위에 머무름.
3
스누즈 / 완료 — 카드에서 바로 처리. 스누즈 탭 → 간격 선택 시트(5·10·30분·1시간). 완료 탭 → 카드가 타임라인의 해당 시각으로 합류 + 체크 표시.
4
오늘 타임라인 — 시간 레일 기준 시간순. 지난·완료 = 60% dim + 체크. 지금 = 정보색 dot 확대. 예정 = 중립 카드.
5
반복 표시 — 반복 알림은 repeat 아이콘 + 규칙 요약("매일 · 정시 + 10분 전"). 다중 리마인더 건수도 함께 노출.
6
알림 카드 탭 — 예정 카드 탭 → 02 생성·편집 폼(편집 모드). 지난 카드는 읽기 전용.
7
내일 미리보기 — 접힘 기본. 펼치면 내일 일정 알림 목록. 그 이후는 "전체 보기"로 분리.
8
새 일정 알림 — 하단 고정 버튼. 탭 → 02 생성·편집 폼(신규 모드). (요청 항목 2·3로 이어지는 진입점)

동작·상태 규칙

·
"방금 울림"은 끈질긴 알림(완료까지 반복)이면 처리 전까지 계속 상단 유지 + 재발화. 1회성 알림은 일정 시간(예: 1시간) 뒤 자동으로 타임라인에 합류.
·
완료/스누즈/지난 처리 상태는 메인 알림 센터와 동기화 — 두 화면이 같은 알림 데이터를 본다.
·
접근성: 타임라인은 시간순 리스트, 각 카드 role="listitem" + 상태를 visually-hidden으로 발성("완료됨 / 예정 / 방금 울림"). 스누즈·완료는 버튼.
·
이 화면은 일정(schedule) 유형 알림 전용 뷰. 시점·미션·달성·관심사 등 전체 알림은 메인 알림 센터에서.

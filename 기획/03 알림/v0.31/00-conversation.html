① 대화창 진입 — 첫 인상 CRITICAL

1
마이크 큰 버튼 + pulse 애니메이션 = 음성이 primary임을 한눈에. 텍스트 입력은 하단 작은 바로 보조. AI 첫 인사 + 추천 발화 4종으로 "뭐라 말해야 하지" 진입장벽 해소.

② 추천 발화 칩

2
4종 — 단순(브리핑/단발 미션) + 복잡(플랜) 골고루. 탭 시 그 발화가 즉시 입력되어 AI 응답 시작. 사용자별 사용 패턴 학습 후 개인화 가능(v0.31 비대상).

③ 단순 케이스 (phone 2) CRITICAL

3
"아침 7시 브리핑" → AI 응답 한 줄 + 결과 미니 카드. Reasoning 노출 X (단순하므로). 결과 카드 = 사용자 결정의 답: 만들어진 게 있고 보러갈 수 있음.

④ 다중 턴 조정 CRITICAL

4
"조금 일찍, 6시 50분" 같은 후속 발화 → AI가 맥락 유지하며 즉시 수정 + 새 결과 카드. 폼으로 들어가지 않고 대화 안에서 모든 조정 완결.

⑤ 복잡 플랜 + thinking (phone 3) CRITICAL

5
"시험 대비 스케줄" → AI thinking dots(스케줄 계산 중) → 응답 + reasoning 박스(왜 이렇게 짰는지) + 결과 미니 카드. Thinking dots는 ChatGPT 패턴 — AI가 일하고 있음을 시각화.

⑥ Reasoning 박스 CRITICAL

6
플랜처럼 여러 결정이 있는 경우에만 노출. "취약 과목 자주·주말 모의고사·시험 임박 시 복습"처럼 사용자가 모르는 사이 들어간 휴리스틱을 명시. 신뢰 + 수정 진입 동기 둘 다 충족.

⑦ 결과 미니 카드 CRITICAL

7
"✓ N개 등록 [보기 →]" 단일 패턴. 플랜이면 07-plan-fullview로, 단발이면 01 알림 센터로. 사용자 결정: 단순 완료 알림 + 보기 탑(사용자 명시).

⑧ 입력 바 — 3 상태

8
① Idle: 마이크 아이콘 + "추가로 말씀해주세요" placeholder
② Listening: wave 파형 + "듣고 있어요" + 빨강 stop 버튼 (phone 2)
③ Text mode: 키보드 + 텍스트 필드 + send 버튼 (phone 1, 3)

분기 — AI가 모호하다고 판단

B
"공부 알림 만들어줘"처럼 정보 부족 시 AI가 되묻기: "언제까지요? 어떤 과목요?" — 다중 턴으로 채워나감. 사용자가 "그냥 일반적으로"면 AI가 합리적 기본값으로 진행 + reasoning에 가정 명시.

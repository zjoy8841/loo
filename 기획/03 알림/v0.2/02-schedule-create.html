인터랙션 매핑

1
빠른 입력 (자연어) — 한 줄 입력 → 날짜·시간·반복 + AI 작업까지 파싱해 폼 자동 채움. 파싱 칩으로 인식 결과 확인. (Todoist 자연어 파서 강점 + AI 작업 확장)
2
AI 작업 블록 — 알림이 울릴 때 AI가 대신 처리할 일. 위에서 아래로 순서대로 실행되고, 뒤 작업은 앞 작업 결과를 입력으로 받음(②는 ①의 검색 결과 사용). 각 블록: 순번 · 능력 아이콘 · 옵션 요약. 핸들로 재정렬, X로 제거.
3
AI 작업 추가 — 점선 버튼 → "AI 작업 추가" 시트. 능력 카탈로그(위치 기반 / 내 프로필 반영 / 정보 정리 / 작성 도움)에서 선택 → 옵션 설정(찾을 곳·범위 등) → "이 작업 추가".
4
결과 미리보기 — "미리보기" 탭 → 울릴 때 받게 될 알림 카드를 시뮬레이션. AI 작업이 1개 이상일 때만 노출.
5
미리 알림 (다중) — 정시 외 N개 추가(10분·30분·1일 전 등). 각 행 X로 제거. (Google Calendar·TickTick 다중 알림) · v0.1 "리마인더" → 통용 표현 "미리 알림"으로 변경.
6
알림 방식 — "한 번만" vs "지속 알림". 지속 알림 = 처리할 때까지 5분 간격 재발화. (TickTick "지속 알림" 공식 용어) · v0.1 "알림 강도/끈질긴 알림" → "알림 방식/지속 알림"으로 변경.
7
카테고리 — 브리핑/일정 알림/미션/관심사. 03 알림 설정의 카테고리 토글과 연동(꺼진 카테고리는 발화 안 됨). v0.1의 "달성"은 제외(달성 판정엔 피드백·웨어러블 트래킹 필요 — 현 단계 보류).
8
저장 / 삭제 — 저장 활성: 제목 1자+ AND 날짜·시간 유효(AI 작업은 선택). 편집 모드에서만 삭제 버튼 노출. 삭제 → 확인 다이얼로그.

AI 작업 — 동작 규칙

·
두 종류의 알림 — AI 작업이 없으면 단순 알림(제목만 알려줌, v0.1과 동일). AI 작업이 있으면 AI 작업 알림(알림 시각에 AI 실행 → 결과를 카드로 전달).
·
자동 실행 — 알림 시각 직전 백그라운드로 실행. 별도 승인 게이트 없이 결과를 바로 카드로 전달(승인형보다 채택률 높음). 자동 실행 on/off·위치 사용은 03 알림 설정 → AI 작업에서 통제. 첫 사용 시 권한 동의 1회.
·
실패·부분 결과 — 한 작업이 실패하면 거기까지의 부분 결과 + 실패 사유 + "다시 시도"를 카드에 노출. 위치 권한 없음 등은 설정 바로가기 안내.
·
데이터 사용 공개 — 각 블록 옵션 요약에 무엇을 쓰는지 명시(현재 위치 / 건강 상태·식단·라이프스타일). 회원가입에서 모은 프로필을 입력으로 사용.

동작·상태 규칙

·
신규/편집 공용 화면. 신규 = 헤더 "새 일정 알림", 편집 = "일정 알림 편집" + 삭제 버튼 + 기존 값 프리필.
·
저장 → 01 타임라인으로 복귀, 해당 시각에 카드 삽입(반복이면 다음 회차 기준). AI 작업 알림은 카드에 AI 마커 표시.
·
접근성: 각 필드 label htmlFor 연결. AI 작업 리스트는 재정렬 가능 리스트(role="listitem" + 순서 키보드 이동), 각 블록의 작업 내용·옵션을 visually-hidden으로 발성. 자연어 파싱 결과·미리보기는 aria-live="polite". 알림 방식 토글은 라디오 그룹.
·
"지속 알림"이 방해 금지 시간과 겹칠 때 동작은 03 설정의 "중요 알림은 방해 금지에도 알림" 값에 따름.

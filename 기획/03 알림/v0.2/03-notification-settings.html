인터랙션 매핑

1
카테고리 토글 — 4종 on/off(브리핑·일정 알림·미션·관심사). 끄면 해당 유형 알림은 발화·수신 안 됨(02 생성 폼의 카테고리와 연동). v0.1 "시점 알림" → 엔드유저 표현 "브리핑". "달성"은 제외.
2
일정 알림 관리 진입 — "내 일정 알림 전체" 탭 → 01 타임라인(= CRUD 허브). 개수 뱃지로 현황 표시.
3
AI 작업 자동 실행 — 켜면 AI 작업 알림이 알림 시각에 자동 실행돼 결과 카드로 발화. 끄면 제목만 알리고 탭 시 수동 실행. (agentic UX — 사용자 통제·동의 표면)
4
위치 기반 작업 허용 — "주변 검색"처럼 위치가 필요한 AI 작업의 데이터 사용 동의. 끄면 위치 작업은 건너뛰고 부분 결과만 전달.
5
기본 알림 — 새 일정 알림 생성 시 02 폼에 자동 적용될 미리 알림 세트. 탭 → 다중 선택 시트. (Google Calendar "기본 알림" 용어 · v0.1 "기본 리마인더"에서 변경)
6
기본 알림 방식 — 한 번만 / 지속 알림 + 재알림 간격(1·5·10분). 신규 생성 기본값. (v0.1 "기본 알림 강도"에서 변경 — "강도"는 통용 표현 아님)
7
방해 금지 시간 — 시작·종료 시각. 이 시간대 알림은 소리·진동 없이 센터에 적립.
8
중요 알림 예외 — 켜면 "지속 알림"은 방해 금지 시간에도 발화(시스템 알람처럼). (TickTick 지속 알림 동작)
9
보관 기간 — 7·30·90일. 지난 알림 자동 정리. 기본 30일.

동작·상태 규칙

·
이 화면 진입점: 01 타임라인 우상단 톱니 / 메인 알림 센터 우상단.
·
모든 토글은 즉시 저장(별도 저장 버튼 없음). 변경 시 aria-live로 "켜짐/꺼짐" 발성.
·
각 상세 행(기본 알림·방식·시간·보관)은 바텀시트로 값 선택. 시트 사양은 별도 화면으로 분리 가능.
·
AI 작업 자동 실행·위치 허용은 첫 사용 시 시스템 권한 동의와 연동. "위치 기반 작업 허용"이 꺼진 상태에서 02 폼에 위치 작업을 추가하면 안내 배너 노출.
·
"달성" 카테고리 보류 사유 — 달성 판정에는 사용자 피드백 또는 웨어러블 기기의 지속 트래킹이 필요. 현 단계에서 어려워 v0.2에서 제외. 트래킹 수단 확보 시 재도입 검토.
·
접근성: 리스트 행은 role="switch"(토글) 또는 button(상세 진입). 카테고리·AI 작업 토글 라벨에 설명 텍스트 aria-describedby 연결.

AI 작업 알림 — 설계 개념

v0.1의 알림은 "정해진 시각에 제목을 알려주는" 단순 리마인더였습니다. v0.2는 알림이 일을 대신 처리할 수 있게 확장합니다.

두 종류의 알림 — AI 작업이 없으면 단순 알림(제목만, v0.1과 동일). AI 작업이 1개 이상이면 AI 작업 알림(알림 시각에 AI 실행 → 결과를 카드로 전달).

순차 실행 파이프라인 — AI 작업 블록은 위→아래 순서로 실행되고, 뒤 작업은 앞 작업의 결과를 입력으로 받습니다. 예: "점심 메뉴 추천" 알림 = ① 주변 식당 검색(위치 기반) → ② 그 식당 메뉴 중 내 건강 상태·라이프스타일을 고려한 추천.

능력 카탈로그 — AI 작업 추가 시트에서 선택: 위치 기반 · 주변 검색내 프로필 반영 · 맞춤 추천정보 정리 · 요약 브리핑작성 도움 · 메시지 초안 각 작업은 옵션(찾을 곳·범위 등)을 갖습니다.

통제·동의·복구 (agentic UX 패턴) — 자동 실행 on/off와 위치 사용은 03 설정에서 통제. 별도 승인 게이트 없이 결과를 바로 전달(승인형보다 채택률 높음). 작업 실패 시 부분 결과 + 사유 + "다시 시도"를 카드에 노출. 사용하는 데이터(위치·프로필)는 각 블록에 명시.

근거: 2026 agentic AI UX 패턴 — 계획 가시성 / 도구 사용 공개 / 사용자 오버라이드 / 우아한 복구. 자동 실행 + 알림 전달 모델이 전면 자율보다 채택률이 높다는 관찰 반영.

용어 검증 — v0.1 → v0.2

v0.1 라벨이 실제 라이프스타일·리마인더 앱에서 통용되는 표현인지 확인하고 교체했습니다.

v0.1 표현 v0.2 표현 근거
기본 리마인더 기본 알림 "리마인더"는 앱마다 제각각. Google Calendar 한국어가 일정 전 사전 알림을 알림·기본 알림으로 표기 — 가장 보편적.
(02 폼) 리마인더 미리 알림 정시·30분 전 등 "이벤트 전 알림"은 Apple 미리 알림이 표준 한국어. 화면 도메인 "일정 알림"과도 층위가 구분됨.
알림 강도 / 기본 알림 강도 알림 방식 / 기본 알림 방식 "강도"를 쓰는 앱 없음. 실제 개념은 1회성 vs 반복 발화 → "방식"이 정확.
끈질긴 알림 지속 알림 TickTick 한국어 공식 용어가 지속 알림(Persistent Notification). "끈질긴"은 비공식·부정 뉘앙스.
스누즈 다시 알림 Apple 미리 알림 한국어 표준. "스누즈"도 통하지만 한국어 표준 표기 우선.
시점 알림 브리핑 "시점"은 프로젝트 내부 용어(6 시점). 엔드유저 카테고리 라벨은 "아침·점심·저녁 브리핑" = 브리핑이 직관적.

Google Calendar

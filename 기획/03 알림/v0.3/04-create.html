섹션 A — 카테고리 우선 동적 폼

1
카테고리 선택 — 일정 알림 / 브리핑 / 미션 / 관심사. 미션 카드는 v0.3 수정으로 "단발 또는 플랜" 두 유형을 안내.
2
브리핑 폼 — 고정 블록 라이브러리에서 체크로 골라 담기. 조립 불필요한 쉬운 경로(약점 3 대비책).
3
미션 폼 · 단발 — 상단 유형 토글(단발/플랜). 단발은 한 시점에 실행되는 AI 작업을 조립. 예시를 v0.2의 "세계 정세"에서 "점심 메뉴 추천"으로 교체 — 사용자가 든 예시이자, 미션=목표 작업이라는 성격에 더 맞음.
·
AI 작업 조립 — 블록별 입력/출력 명시 + 커넥터로 데이터 흐름 가시화(약점 3 보완). ① 주변 식당 검색 → ② 메뉴 추천.
·
"브리핑 vs 미션"이 v0.3에서 모호했던 문제 — 미션 예시를 정보 수집형("세계 정세")에서 목표 작업형("점심 추천")으로 바꿔 경계를 분명히. 정보를 모아 보는 건 브리핑, 목표를 향해 AI가 일하는 건 미션.

섹션 B — 미션 플랜 (목표 기반 스케줄 생성)

"점심 메뉴 추천"은 한 시점의 작업(=단발). 하지만 "중간고사 공부 스케줄"·"요일별 학업 스케줄"은 여러 날에 걸친 알림 묶음이라 단발 폼으로 안 됨. 그래서 미션에 플랜 유형을 추가 — 목표를 주면 AI가 스케줄을 생성한다.
4
플랜 입력 (폰4) — 목표 + 공부할 범위·성취 기준 + 기간 + AI 스케줄 방식 + 알림 시간대. 마지막에 "AI 스케줄 생성".
·
목표 — 자연어로. "취약한 수학에 더 집중" 같은 의도까지 적으면 스케줄 배분에 반영.
·
범위·성취 기준 — 과목별 단원. "성취 기준 불러오기"로 교육과정 성취기준을 끌어와 범위·난이도 배분의 근거로 사용(요일별 학업 스케줄 케이스).
·
기간 — 마감형 / 반복형 — 마감형 = 시험일까지 D-day 카운트다운(중간고사). 반복형 = 마감 없이 요일별로 계속(요일별 학업 스케줄). 한 폼으로 두 케이스를 다 담음.
·
AI 스케줄 방식 — 취약 과목 가중·주말 모의고사·임박 시 복습 전환 등. AI가 스케줄을 짤 때의 규칙.
5
생성 결과 미리보기 (폰5) — AI가 짠 요일별 스케줄. 상단에 플랜 요약(기간·알림 개수·과목 배분·D-day). 각 항목은 눌러서 시간·내용 편집·삭제. "다음 주 보기"로 전체 확인.
·
다시 짜달라기 — 결과가 마음에 안 들면 AI에게 재생성 요청(피드백 한 줄 첨부 가능).
·
저장 = 알림 묶음 등록 — 플랜 1개 = 미션 1개가 N개 알림을 소유. 저장하면 각 알림이 01 센터·03 타임라인에 개별 인스턴스로 뜨고, 플랜 단위로 묶여 보임.

동작·상태 규칙

·
플랜의 개별 알림도 AI 작업·정시성 모델 적용 — 예: 공부 알림이 울릴 때 그날 범위의 핵심 요약·문제를 함께 전달 가능.
·
반복형 플랜은 성취 기준 진척에 따라 AI가 다음 주 스케줄을 조정 제안(미달 범위 보강). 자동 적용이 아니라 "제안 → 확인".
·
플랜 편집: 개별 알림 수정은 그 알림만, 플랜 목표·범위 변경은 "전체 다시 생성"으로. 이미 지난 알림은 보존.
·
플랜 삭제: "이후 알림만 삭제 / 전체 삭제" 선택. 지난 기록은 남길 수 있음.
·
접근성: 생성 결과는 요일·날짜 순서가 있는 리스트. 각 항목 "요일·시각·과목·내용"을 한 묶음으로 발성. "AI 스케줄 생성"·"다시 짜달라기" 후 결과는 aria-live로 안내. 플랜 요약의 D-day는 텍스트로도 제공.

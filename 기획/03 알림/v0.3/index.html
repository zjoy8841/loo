U-04 알림 · v0.3 초안

v0.2에 대한 시니어 기획자 검토에서 나온 약점 5가지를 보완한 버전. 빠져 있던 소비 표면(알림 센터·알림 도착)을 새로 그리고, 생성 폼을 카테고리 우선 구조로 재설계하고, AI 작업의 정시성·조립·제어를 정식 설계로 끌어올렸습니다.

그레이스케일 + 라인 아이콘 시멘틱 색: 정보 파랑만 v0.3 = 약점 5종 보완

v0.3 수정 ① — 목표 기반 스케줄(플랜) 추가 · 2026-05-15

"점심 메뉴 추천"은 한 시점 작업(단발 미션)으로 이미 가능하지만, "중간고사 공부 스케줄"·"학업 성취기준 기반 요일별 학업 스케줄"처럼 여러 날에 걸친 알림 묶음은 단발 폼으로 담을 수 없었음. → 미션 카테고리에 단발 / 플랜 두 유형을 도입. 플랜 = 목표·범위·기간을 주면 AI가 요일별 알림 스케줄을 생성(04), 묶음으로 등록되어 01 센터에 플랜 태그로 표시.

v0.3 수정 ② — 실패 시트 명시 · 2026-05-15

02 알림 도착의 잠금화면에 실패 알림 카드(빨간 강조 + 다시 시도/부분 결과 미니 버튼) + 새 실패 시트(폰4) 추가. 진행 시트와 같은 골격에서 단계 표시·부분 결과·사유·액션을 실패 변형으로 정의(완료 ✓ → 실패 ! / 액션은 "작업 멈춤·나중에 보기" → "다시 시도·직접 보기").

v0.3 수정 ③ — 06 결과 상세 신규 · 2026-05-15

정상 도착한 AI 작업 알림을 탭했을 때의 풀뷰 화면이 비어 있었음. 06 결과 상세를 신규 작성 — 잠금화면 카드·배너·01 센터 카드 탭의 공통 도착지. 결과 종류별 콘텐츠 분기(폰1 = 브리핑 긴 콘텐츠형 / 폰2 = 추천 리스트+지도형), 공통 footer 액션(다시 받기·저장·공유·더 묻기). 다른 앱들의 "알림 = 미리보기, 탭 = 앱 안 풀뷰" 패턴을 채택.

시니어 검토 약점 → v0.3 보완

v0.2를 시니어 기획자 시점에서 비판적으로 검토해 도출한 약점 5가지와, 각각을 v0.3에서 어떻게 보완했는지.

v0.3 핵심 개념

정시성 모델 — 알림의 정시성과 AI 결과를 분리한다. 알림은 항상 정각에 뜨고(필요하면 "준비 중" 상태로), 결과는 준비되는 대로 같은 알림을 갱신한다. 결과 때문에 알림이 늦지 않는다.

카테고리 = 폼의 종류 — 카테고리는 알림의 종류이자, 04 생성 폼의 분기이자, 05 설정의 on/off 단위. "사용자가 만든 것"과 "시스템이 주는 것"을 카테고리 축으로 정리.

AI 작업 = 보이는 파이프라인 — 조립을 유지하되, 블록의 입력/출력과 블록 간 데이터 흐름을 명시해 "무엇이 무엇으로 이어지는지" 보이게. 조립한 블록은 그대로 02 알림 도착의 진행 단계가 된다.

제어 위계 — 전역 기본값은 05 설정, 개별 알림·카테고리의 즉시 제어(멈춤·일시중지·끄기·작업 취소)는 01 센터 롱프레스. "어디서 끄지?"를 없앤다.

미션 = 단발 + 플랜 — 미션은 목표 기반 카테고리. 한 시점의 AI 작업은 단발(점심 메뉴 추천), 목표를 주면 AI가 여러 날 알림을 생성하는 건 플랜(중간고사 공부·요일별 학업 스케줄). 플랜 1개 = 미션 1개가 N개 알림을 소유한다.

용어 (v0.2 검증 결과 유지)

기본 알림 · 미리 알림 · 알림 방식 · 지속 알림 · 다시 알림 · 브리핑 — v0.2에서 라이프스타일 앱 통용 표현으로 검증·교체한 용어를 v0.3에서도 그대로 사용. v0.3 신규 용어(알림 요약·조용히 전달·긴급 즉시 전달)는 Apple iOS 한국어 표기를 차용.

인터랙션 매핑 (Phone 1) v0.3 재정의

1
화면 역할 = 알림 규칙 관리 — "오늘 인스턴스 리스트"가 아니라 사용자가 만든 알림 규칙 단위 리스트. 각 카드 = 1개 반복 규칙 = "반복 패턴 + 시간 + 작업". 예: 매주 월요일 7:00 주간 브리핑 · 매 10일 9:00 건강 점검.
2
카드 layout — 시간 column 제거. 카테고리/작업 아이콘 + 작업명(primary) + 메타 한 줄(반복 + 시간 + 카테고리 + 다음 발생). 예: "매일 7:00 · 브리핑 · 다음 내일 7:00". 시간이 작업명에 부속.
3
반복 패턴 표기 다양화:
  • 매일 — 아침 브리핑·저녁 운동·취침 준비
  • 매 평일 — 점심 메뉴 추천 (주말 제외)
  • 매주 요일 — 매주 월요일 7:00 주간 브리핑
  • 매 N일 — 매 10일 건강 점검 (interval 반복)
  • 한 번 — 5/16 10:00 강남 클라이언트 미팅 (단발)
  • 플랜 묶음 — 매일 학습 · 5/15~7/17 (기간 + 반복)
인스턴스/시점 단위(오늘만·done/now/upcoming)는 더 이상 grouping 기준이 아님 — 그건 알림센터의 영역.
4
카드 탭 → 04 생성·편집 편집 모드(prefill). 플랜 카드 탭만 예외 → v0.31 07 플랜 풀뷰(묶음 단위라 별 화면).
5
스와이프 시연 (19:00 카드) 3 액션 재정의 — 인스턴스 단위가 사라지면서 "이 알림만 / 일정 전체" 분리도 의미 약함. 새 3 액션:
  • 수정 (파랑) — sheet 진입 (Phone 2)
  • 일시중지 (주황) — 규칙을 임시로 끔. 언제든 다시 켤 수 있음. "오늘만 건너뛰기" 옵션은 일시중지 sheet 안에서 분기.
  • 삭제 (빨강) — 규칙 영구 삭제(되돌릴 수 없음 · confirm 필수).
6
일시중지된 알림 ⌄ — 펼치면 임시 비활성화된 규칙 모음. 카드 탭으로 다시 켜기 · 영구 삭제 진입. "내일 미리보기" 같은 시간 grouping 버튼은 제거(이 화면은 규칙 단위라 시간 prefix는 메타로 충분).
7
새 일정 알림 — 하단 고정. 진입은 00 대화창이 primary(음성 1발화로 규칙 1개 생성), 04 폼 직진은 보조. 현재는 04 폼 prefill로 임시 link.

수정 시트 (Phone 2) — v0.3 신규

8
Bottom sheet 패턴 — Phone 1의 수정 탭 → 하단에서 올라오는 시트(~75% height). 위쪽 dimmed 영역은 원래 리스트가 보임(컨텍스트 유지). 시트 핸들(━) + ✕ 닫기로 dismiss.
9
현재 설정 개요 — 시간·미리 알림·반복·카테고리·AI 작업 5 필드 readonly 표시. 사용자가 "지금 어떻게 설정되어 있더라"를 즉시 인지 → 무엇을 바꿀지 판단.
10
음성으로 수정 (primary · 검정) → v0.31 00 대화창으로 진입. 이 알림의 컨텍스트가 자동 전달됨 — 대화창에서 AI 첫 인사가 "저녁 운동 미리 알림 수정. 어떻게 바꿀까요?"로 시작. 빠른 변경에 적합("6시 50분으로 옮겨" · "수요일은 빼" · "AI로 운동 추천도 받게 해").
11
직접 수정 (line · 보조) → 04 생성·편집 폼 prefill. v0.31에서 보조 경로로 격하한 04 폼의 명확한 사용 경로 = 편집. 폼에 현재 값들이 미리 채워져 있고 사용자가 필드 단위로 변경. 정밀 변경에 적합(미리 알림 옵션 추가 · 카테고리 변경 · AI 작업 블록 연결 등).
12
반복 일정 분기 — 사용자가 시트에서 변경을 시작하면 시스템이 "오늘만 / 이 일정 전체 / 앞으로의 일정" 3 선택지를 묻는 단계가 음성 또는 폼 안에 들어감(iOS Calendar 패턴).

동작·상태 규칙

·
이 화면은 일정(schedule) 카테고리 전용 관리 뷰. 브리핑·미션·관심사 등 다른 카테고리는 01 알림센터의 다른 필터(또는 별 관리 화면)로.
·
스와이프 액션 width = 3 버튼 × 80px = 240px. 카드를 -240px translate. CSS transition 250ms ease-out.
·
"일정 전체 삭제"는 비가역 → confirm 다이얼로그 필수. "수정"과 "이 알림만"은 즉시 적용 + Undo 토스트(5초).
·
접근성: 각 row role="listitem" + 시간·제목·반복을 visually-hidden 발성. 스와이프 액션은 button + aria-label. 시트는 role="dialog" aria-modal="true".

플랜 묶음 카드 (Phone 1)

13
플랜 1개 = 1 row (묶음 단위) — 플랜의 개별 학습 알림(14:00 영어·20:00 과학 등) 인스턴스가 따로 표시되지 않고 "중간고사 학습" 플랜 자체가 한 카드. 사용자가 만든 알림 규칙 단위 정합 — 플랜도 규칙 묶음 1개. 인스턴스를 보려면 → 07 플랜 풀뷰.
14
플랜 카드 시각 차별화:
  • 옅은 파랑 배경(#f8fafc) + 파랑 테두리
  • book-open 아이콘 + 파랑 "플랜" 태그
  • 메타: "매일 학습 · 5/15~7/17 · 64개 알림 · D-22" — 반복 패턴 + 기간 + 묶음 크기 + 마감
탭 → v0.31 07 플랜 풀뷰 진입. 플랜 풀뷰에서 각 인스턴스 시간순 + 진행률 확인.
15
플랜 카드의 스와이프 액션 — 일반 알림 카드와 동일한 3 액션이지만 의미 다름:
  • 수정 → 07 플랜 풀뷰의 "대화로 수정" 또는 "재생성" 진입 (개별 인스턴스가 아닌 플랜 전체 조정)
  • 일시중지 → 플랜 자체 일시 정지 (재개 시 남은 기간의 알림만 다시 활성)
  • 삭제 → 플랜 전체 종료 (모든 학습 알림 사라짐) · confirm 필수

편집 폼 (Phone 3) — v0.3 신규

16
v0.31에서 격하한 04 폼의 명확한 도착지 = 편집. 신규 생성 = 00 대화창(primary), 편집 = 04 폼(prefill, primary). 폼은 "정밀 도구"가 되어 신규 사용자는 만질 일이 없고, 정확한 변경 필요할 때만 진입.
17
Prefill 안내 박스 — 상단 파란 배너 "기존 값에서 편집 중 · 변경한 항목만 저장". 현재 상태에서 출발임을 인지 + "안 건드린 건 그대로" 시그널 → 사용자 불안 ↓.
18
필드 7개 + 액션 1개:
  • 알림 이름 — text input
  • 시간 — time picker(시계 아이콘)
  • 미리 알림 — chip group ("10분 전 ✕", "+ 추가" dashed)
  • 반복 — segmented (매일·주중·주말·요일·안 함)
  • 카테고리 — drop (일정·브리핑·미션·관심사)
  • 알림 방식 — drop (기본·조용히·지속·요약)
  • AI 작업 — 선택 dashed button("운동 추천" 예시), 미선택 시 비어있음
  • 이 알림 삭제 — 폼 하단 빨강 line button
19
저장 = 상단 우측 dark CTA (iOS Settings 패턴). 변경 후 저장 → 시트 닫힘 + Phone 1 복귀 + 변경된 row가 잠시 강조(blue flash 1초).
20
AI 작업 추가 → 별도 카탈로그 시트(운동 추천·식단·기상 음악 등) + 옵션 설정. 후속 라운드 미작성.

미결 — 보완 대상

·
진입 트리거 — 이 화면으로 들어오는 경로 미정 (사용자 질문). 후보: ① 알림센터 segmented 토글 ② 알림센터 헤더 ⏱ 아이콘 ③ 메인 위젯 ④ 05 설정 안 항목. 별도 결정 라운드. 현재는 01에서 ← back으로 임시 link.
·
04 폼 본 파일 갱신 — Phone 3은 시각 prototype. 실제 04-create.html은 아직 v0.3 카테고리 우선 동적 폼. retrofit으로 갱신 필요(편집 모드 prefill + 신규 모드 분기).
·
플랜 인스턴스 수정 범위 분기 — iOS Calendar 패턴 차용: "이 일정만 / 앞으로의 일정 / 모든 일정" 3 옵션. 폼 저장 또는 음성 수정 확정 직전 단계로 삽입.
·
AI 작업 카탈로그 시트 — 운동 추천·맞춤 식단·기상 음악 등 옵션 + 블록별 파라미터. v0.4 후속 라운드.

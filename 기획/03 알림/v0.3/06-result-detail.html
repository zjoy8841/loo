역할 — 빠진 자리 채움

v0.3까지 알림 도착(02)·진행 중·실패는 다뤘지만, "정상 도착한 결과를 풀뷰로 보는 화면"이 비어 있었음. 06이 그 자리. 잠금화면 카드 / 배너 / 01 센터 카드 탭의 공통 도착지 — 다른 앱들이 뉴스·메일·일정에서 "알림 = 미리보기, 탭 = 앱 안 풀뷰"로 두는 패턴을 그대로 채택.

진입 경로

·
잠금화면 결과 카드 탭 (02 폰1) → 06. iOS rich notification 식의 in-place 확장도 보조로(짧은 미리보기 더 보기).
·
배너 탭 (02 폰2) → 06.
·
01 센터의 결과 카드 탭 → 06. 카드의 "다른 추천"·"지도" 같은 inline 액션은 06으로 안 가고 그 자리에서 처리.
·
플랜 알림 탭 → 06(그날 알림 결과) + 상단에 "이 알림은 [중간고사 공부 스케줄]의 일부 → 플랜 전체 보기" 링크 노출.

인터랙션 매핑

1
메타·제목 헤더 — AI · 카테고리 태그 + 도착 시각 + 제목 + 한 줄 설명. 어떤 알림이 어떤 결과를 가져왔는지 즉시 파악.
2
브리핑 폰1 — 긴 콘텐츠형 — AI 종합 요약(파란 박스) + 헤드라인 리스트(소스·제목·한 줄). 헤드라인 탭 → 원본 기사(외부 링크). "나머지 N건 보기"로 펼침.
3
추천 폰2 — 리스트+지도형 — 1순위 추천(hero) + 지도 미리보기(핀들) + 다른 후보 리스트. 후보 탭 → 그 후보를 1순위 자리에 교체 + 지도 핀 갱신. 지도는 "지도에서 보기"로 풀 지도 진입.
4
액션 행위(공통 footer) — 다시 받기/추천(같은 알림을 즉시 재실행) · 저장(나중에 다시 볼 결과 보관) · 공유(외부 앱) · 더 묻기(이 결과를 컨텍스트로 AI에게 추가 질문).
5
"AI가 어떻게 만들었나요" 펼침 — 04에서 조립한 AI 작업 단계가 여기서 결과 근거로 노출(투명성). 어떤 데이터를 썼는지 — 위치·건강·식단·관심 분야 등 — 도 명시.
6
다음 도착 — 같은 알림이 언제 다시 오는지 한 줄로. 끄거나 시간 바꾸려면 우상단 "더보기 (⋯)" → 알림 설정 / 일시중지 / 끄기.

동작·상태 규칙

·
결과 종류별 콘텐츠 분기는 같은 화면 패밀리 안에서 처리 — 헤더·footer·메타는 공통, 본문 컴포넌트만 다름. (브리핑 = 요약+헤드라인 / 추천 = hero+지도+후보 / 플랜 인스턴스 = 학습 내용+자료+플랜 컨텍스트)
·
짧은 결과(예: 점심 1순위만 카드에 다 들어가는 경우)는 01 센터 카드의 inline 액션만으로 충분. 06 진입은 "더 보기"가 의미 있을 때(다른 후보·지도·근거를 보고 싶을 때)만.
·
"다시 받기"는 새 알림을 만들지 않고 같은 알림 객체의 결과만 재생성(02의 정시성 모델 재사용 — 준비 중 → 결과 갱신).
·
"저장"한 결과는 별도 보관함에 쌓임(보관함 화면은 다음 라운드 미결).
·
접근성: 헤드라인·후보 리스트는 role="list" + 각 항목 외부 링크 여부를 visually-hidden 발성. 지도 미리보기는 장식이 아니므로 aria-label로 "추천 식당 위치 지도, 핀 3개" 발성. "AI 어떻게 만들었나요"는 aria-expanded. footer 4개 액션은 라벨이 아이콘 아래 텍스트로 노출되어 스크린리더 네이티브.

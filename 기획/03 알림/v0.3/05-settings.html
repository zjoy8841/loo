인터랙션 매핑

1
카테고리 토글 — 4종 on/off(브리핑·일정 알림·미션·관심사). 끄면 해당 카테고리 알림은 발화 안 됨. 04 생성 폼의 카테고리와 같은 단위.
2
알림 요약 v0.3 신규 — 긴급하지 않은 알림을 정해진 시각(아침 8:00·저녁 8:00)에 모아 1개 그룹으로 전달. 01 센터의 "요약 그룹" 카드가 그 결과. (Apple "시간 지정 요약") 탭 → 시각·포함 카테고리 설정.
3
조용히 전달 (기본) v0.3 신규 — 켜면 새 알림이 소리·진동 없이 센터에만 쌓임. 앱 전체 기본 전달 방식. 카드별 예외는 롱프레스로. (Apple "조용히 전달")
4
긴급 알림 즉시 전달 v0.3 신규 — 지속 알림·마감 임박 알림은 요약·조용히 전달을 건너뛰고 바로 발화. (Apple "항상 즉시 전달")
5
알림·플랜 관리 — "내 일정 알림 전체" → 03 타임라인(CRUD 허브). "미션 플랜" → 목표 기반 스케줄(중간고사 공부·요일별 학업) 목록 — 편집·다시 생성·삭제. v0.3 수정으로 플랜 항목 추가.
6
AI 작업 — 자동 실행(선실행) on/off + 위치 기반 작업 허용. 자동 실행 설명을 v0.3 정시성 모델("10분 전 선실행 → 정각 결과")에 맞춰 갱신.
7
기본값 — 기본 알림(미리 알림 세트) · 기본 알림 방식(한 번만/지속). 04 생성 폼에 자동 적용.
8
방해 금지 — 시간대 + "중요 알림은 방해 금지에도 알림" 예외.
9
보관 기간 — 7·30·90일. 01 센터 "이전" 영역 자동 정리. 기본 30일.

제어 위계 — 전역 vs 개별 (약점 5)

전역 기본값은 이 설정 화면에서, 개별 알림·카테고리의 즉시 제어(멈춤·일시중지·끄기·작업 취소)는 01 센터의 카드 롱프레스 메뉴에서. 둘을 분리해 "어디서 끄지?"를 없앰.
·
모든 토글은 즉시 저장. 변경 시 aria-live로 "켜짐/꺼짐" 발성.
·
각 상세 행(요약·기본 알림·방식·시간·보관)은 바텀시트로 값 선택.
·
접근성: 리스트 행은 role="switch" 또는 button. 토글 라벨에 설명 텍스트 aria-describedby 연결.

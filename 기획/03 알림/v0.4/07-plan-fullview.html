플랜 관리

대화로 수정

① 진입 경로 CRITICAL

1
도달 경로 3가지:
  • 대화 결과 미니 카드 "보기 →" (00 conversation)
  • "전체 스케줄 보여줘" 명령형 대화 응답
  • 알림 센터(01)에서 플랜 태그 알림 탭

② Hero 진행 — D-day + 진행률 CRITICAL

2
"7월 17일까지 D-63일" — 목표 일자 강조. 진행률·완료/남음 stat 3개로 한눈에 상태 파악. AI 플랜 배지로 "이건 AI가 만든 거"라는 출처 명시.

③ 주차 탭

3
9주 플랜이면 9개 탭. 지나간 주는 done(취소선), 이번 주 = on, 미래 = idle. 가로 스크롤. 사용자 결정: 주 단위가 멘탈 모델(64일 한 그리드는 너무 큼).

④ 일자 카드 CRITICAL

4
오늘 = 파란 강조. 각 카드 = 그날 알림 풀 리스트. 시간 · 과목 pill · 작업 라벨 · 체크박스. 과목별 색(수학·영어·과학·모의·복습)으로 균형 시각화 — AI가 짠 reasoning(취약 자주·주말 모의)이 한눈에 보임.

⑤ 과목 pill 색 시스템

5
색은 정보용(미적 X). 사용자가 "수학 더 자주" 같은 요청을 했을 때 그리드 보면 즉시 검증. 색은 AI가 자동 배정(과목 추가 시 색상 풀에서 선택).

⑥ 액션 바 — 대화로 수정 CRITICAL

6
3개 액션:
  • 대화로 수정 (파랑·primary) → 00 conversation, 플랜 컨텍스트 유지한 채로 추가 발화
  • 재생성 → AI에게 같은 목표 다른 스케줄 요청 (현재 진행도 유지)
  • 종료 (위험) → 플랜 종료, 남은 알림 모두 취소
"대화로 수정"이 primary = v0.4 패러다임. 폼 편집은 보조 경로(05 edit retrofit).

⑦ 헤더 마이크 — 빠른 대화

7
우상단 마이크 = 풀뷰 보면서 즉시 대화 시작. "오늘 거 다 해" / "수학 빼" 같은 빠른 명령용.

⑧ 명령형 대화 — "전체 스케줄 보여줘"

8
00 conversation에서 사용자가 "전체 스케줄 보여줘"라고 말하면 AI 응답: "시험 대비 학습 플랜이에요. 전체로 열까요? [열기 →]" — 탭 시 이 화면. 플랜 1개 = 인라인 카드 미리보기 + 풀뷰 진입, 여러 개 = 플랜 목록 sheet 후 선택.

분기 — 여러 플랜 동시 진행

B
플랜 N개면 hero 위에 plan switcher(스와이프 또는 segmented control). 각 플랜이 같은 구조의 풀뷰. 알림 센터(01)에서도 플랜 태그로 필터.

접근성

A

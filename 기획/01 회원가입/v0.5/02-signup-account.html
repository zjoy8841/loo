⚙ Fragment 사용 규칙

  • Base = "이 화면 1개" — Figma 캐노니컬 base 프레임에 해당.
  • Fragment = "이 부품이 이 상태일 때" — Figma에서 Base 위에 슬라이스로 교체/오버레이.
  • 색은 시멘틱 4종(에러·경고·성공·정보). 실제 hex는 디자인 가이드 토큰에서 확정.
  • 이모지 금지. 모든 시각 시그널은 라인 아이콘(Lucide 스타일 SVG, stroke 1.8).
  • 인터랙션 동작 사양(debounce ms · API endpoint · aria 속성)은 노션 description 책임.

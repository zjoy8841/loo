⚙ select 동작 사양 (개발용 노트)

  • 연 옵션: 1900 ~ (오늘 연도) 내림차순. 사용자 컨퍼트를 위해 최근 30년 디폴트 + "더 보기"로 확장 가능. 또는 풀 list.
  • 월 옵션: 01 ~ 12 고정.
  • 일 옵션: 선택된 연·월에 따라 동적 (28/29/30/31). 윤년 = 연 % 4 == 0 AND (연 % 100 != 0 OR 연 % 400 == 0).
  • 미래 날짜 차단: select 옵션 생성 시 오늘(YYYY-MM-DD) 이후는 disabled 처리 또는 옵션 자체 미생성. new Date() > selectedDate 가드 추가.
  • 14세 미만: 가입 자체는 허용하되 warning 노출. 정책상 차단이면 zod refine로 막음 — 노션 description 결정.
  • 이모지 금지. 모든 시각 시그널은 라인 아이콘.

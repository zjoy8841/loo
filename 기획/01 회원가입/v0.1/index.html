v1.0 시안의 5가지 약점을 보완한 초기 와이어프레임 (색·아이콘 제거)

시니어 기획자 리뷰 — 5가지 약점

  1. 건너뛰기 옵션이 모든 단계에 존재 → 추천 정확도 핵심 데이터까지 누락 가능
  2. 약관 동의(이용약관·개인정보·마케팅) 단계 부재 → 한국 법적 필수 누락
  3. 단일 선택 vs 복수 선택 시각적 구분 부재 → 같은 chip 모양으로 혼동
  4. 각 단계 입력의 데이터 활용 미리보기 부재 → "왜 입력하나" 가치 불명확
  5. 계정 단계 입력 검증·피드백 슬롯 부재 → 에러 표시·비밀번호 강도 미표시

v0.1 반영 사항

  • 건너뛰기 정리: 계정 단계는 건너뛰기 제거. 나머지는 "나중에 입력 · 권장 안 함" 라벨
  • 약관 동의: 계정 단계 하단에 필수 2 + 선택 1 체크박스 슬롯
  • 선택 구분: chip 우상단 □(복수) / ○(단일) 마커
  • 데이터 활용: 각 단계 상단에 "사용처: 메인 → OO 카드" 미리보기
  • 입력 검증: 계정 input 아래 검증 슬롯 + 비밀번호 강도 4단계 미터

# 추천 알고리즘 정책 v0.1

> **큐레이션 도메인(U-15)의 콘텐츠·가맹점·뉴스 추천 알고리즘 정책 문서.**
> 정적 가중치(코호트 기반) + 동적 학습(활동 로그 기반)을 결합한 하이브리드 모델.

**SSoT**: 노션 페이지가 캐노니컬. 본 markdown은 미러 (타 팀원 git 클론으로 가져갈 수 있게).

## 핵심 요약

사람 호불호는 자꾸 바뀌기 때문에 가중치를 고정으로 박을 수 없다. **초기 코호트 가중치 + 행동 학습 + 시간 감쇠 + 다양성 부스트 + 부정 신호 처리**의 5개 층이 엮인 하이브리드 모델을 사용한다.

```
최종 가중치 = 코호트 기본 (성별·나이·직업)
            + 활동 점수 × 시간 감쇠
            + 다양성 부스트
            − 부정 신호
            ± 20% 탐험 슬롯
```

## 1. 콜드 스타트 정적 가중치 표 (가입 직후)

활동 기록이 없는 신규 사용자에게 높이는 **코호트 기본값**. 성별 × 연령대 × 직업 코호트별 카테고리 선호 추정치.

### 1-1. 적용 대상

- 뉴스 (아침 관심사·점심 속보·저녁 주요)
- 가맹점 추천 (아침 출근길·점심·저녁)
- 콘텐츠 (저녁 영화·드라마·웹툰)
- 생일 쿠폰 대상 가맹점

### 1-2. 가중치 매트릭스 예시 — 30대 직장인

가중치는 0이 중립, +수치는 상위 노출 강화, −수치는 노출 감소.

| 카테고리 | 남 30대 직장인 | 여 30대 직장인 | 학생 | 프리랜서 |
|---|---|---|---|---|
| 정책 | +10 | **+30** | 0 | +10 |
| 경제 | **+30** | +25 | +5 | +20 |
| IT/테크 | +20 | +10 | **+30** | **+30** |
| 사회 | +15 | +15 | +10 | +10 |
| 라이프·패션 | +5 | **+20** | +15 | +10 |
| 스포츠 | +20 | −5 | +15 | +10 |
| 육아·교육 | +5 | +15 | 0 | +5 |
| 음식·요리 | +15 | +20 | +15 | +15 |
| 여행 | +15 | +20 | +20 | +25 |
| 자기계발 | +15 | +15 | +20 | +15 |

위 수치는 **예시**. 실제 항목·수치는 운영 데이터로 조정. 개발 문서에 서르이아와 함께 설정.

### 1-3. 성별 "선택 안 함" (UNDISCLOSED) 처리

- 성별 코호트 분기 미적용
- 나이 · 직업 기본값만 동작
- 몇주 활동 누적 후 행동 학습으로 보완

## 2. 활동 학습 룰 (행동 → 가중치 변화)

사용자가 앞으로 하는 행동 = 추천이 맞았다고 판단 → 해당 카테고리 가중치 ↑. 반대 행동도 동일한 방식으로 ↓.

### 2-1. 강력한 긍정 신호 (가중치 ↑↑↑)

| 행동 | 가중치 변화 | 대상 카테고리 |
|---|---|---|
| 가맹점 예약·결제 | +5 | 해당 가맹점 + 유사 업종 |
| 뉴스 완독 + 라이언에게 말하기 | +4 | 해당 카테고리 |
| 저장·공유 | +3 | 해당 카테고리 |
| 좋아요 | +2 | 해당 카테고리 |

### 2-2. 약한 긍정 신호 (가중치 ↑)

| 행동 | 가중치 변화 |
|---|---|
| 카드 클릭 + 30초 이상 처르기 | +1 |
| 가맹점 텍스트 클릭 (예약 안 함) | +1 |
| 메인 화면에서 카드 노출 (클릭 없이) | +0.1 |

### 2-3. 부정 신호 (가중치 ↓)

| 행동 | 가중치 변화 |
|---|---|
| 카드 노출 후 3초 이내 닫음 (빠른 이탈) | −2 |
| "관심없음" 또는 "이 대주제 그만 보기" 탭 | −5 |
| 예약 취소 | −3 |
| 같은 카테고리 7일 연속 노출이지만 클릭 없음 | −1/일 |

### 2-4. 가중치 합산 시점

- 실시간 반영 (행동 즉시 가중치 갱신)
- 다음 추천 시 적용
- 단일 일일 활동 래턴한 합해도 되면 최대 +20 / −20으로 제한 (한 번의 이상 행동이 전체를 흔들지 않도록)

## 3. 시간 감쇠 (decay)

오래된 행동은 점점 영향을 줄인다. 최근 행동에 더 무게를 주고, 의미 없게 오래된 건 끊는다.

### 3-1. 감쇠 공식

```
행동 점수 × 감쇠 계수 = 적용시 점수

경과 시간         감쇠 계수
0–7일         1.0 (만점)
8–30일        0.5
31–90일       0.2
91일 이상      0.0 (소멸)
```

### 3-2. 예시

- 2주일 전 "경제 뉴스 완독" 행동 → 원래 +4 × 0.5 = **+2**
- 2달 전 "정책 뉴스 좋아요" → +2 × 0.2 = **+0.4**
- 4개월 전 행동 → 계산에서 제외

### 3-3. 가맹점·뉴스 각자 다른 감쇠 속도?

- **가맹점**: 위와 같은 속도 (단골 패턴 보존)
- **뉴스**: 더 빠르게 감쇠 (시사 흐름이 빠르기 때문에). 0–3일 완전 반영, 4–10일 0.5, 11일+ 0.1
- **콘텐츠 (영화·드라마)**: 느리게 감쇠 (장기 취향이라). 0–30일 만점, 31–180일 0.5, 181일+ 0.2

## 4. 다양성 + 탐험 비율

같은 카테고리만 계속 추천하면 사용자는 지루해지고 새 관심사 발견도 안 됨. 강제로 다양성 확보.

### 4-1. 카드 N장 노출 시 채움 룰

| 카드 슬롯 | 채우는 방식 | 비율 |
|---|---|---|
| 안전 추천 | 가중치 상위 카테고리 | **70%** |
| 한단계 아래 카테고리 (다양성) | 2·3위 카테고리 | **20%** |
| 탐험 슬롯 | 머신 카테고리 · 새 시도 | **10%** |

카드 10장이면 = 7장 상위 카테고리 / 2장 다양성 / 1장 탐험.

### 4-2. 탐험 슬롯 선택 룰

- 동일 세대·직업·성별 코호트의 인기 카테고리 중 **본인이 안 본 것**
- 일정 기간(예: 3일) 안 본 카테고리는 탐험에서 제외
- 탐험 카드 결과 합시 클릭 / 완독 → 해당 카테고리의 기본 가중치 증가
- 탐험 3일 연속 무반응 → 멸시 신호, 다른 시도

### 4-3. 카테고리 적당 최소·최대 한계

- 한 카테고리가 전체 카드의 50% 초과 귀속 없음 (대세 쓸림 방지)
- 가중치 최상위도 최소 1장만 수행 (아주 극단적 분포 방지)

## 6. 진화 룰 (회의록 5/28 결정)

사용자는 생애주기가 길어서 사용 횟수가 높아질수록 "개인화"가 세부화되어야 함. 회의록 결정: **"학습"이 아닌 "데이터 정제 + 순위 변경"** 프레임으로.

### 6-1. 메인 세 단계 (회의록 장면)

| 단계 | 조건 | 동작 |
|---|---|---|
| 첫 방문 | 가입 후 1회 이내 | 등록 가맹점 10개 모두 노출 (코호트 기본값만 적용) |
| 둘째 방문 | 예약 한 가맹점 존재 | 예약했던 가맹점 더 위로 수렴 상승 · 활동 학습 대차원 주입 |
| 셋째 방문 이상 | 2주일 수련 누적 N개 | 비슷한 업종 우선 · 무관한 건 하위로 내림 |

### 6-2. 고도 학습으로 전환되는 분기점

- 활동 로그 누적 N개 이상이면 활동 학습의 비중이 코호트 기본값을 초과
- 3회 방문 이하 = 코호트 80% + 활동 20%
- 4–30회 = 코호트 50% + 활동 50%
- 31회 이상 = 코호트 20% + 활동 80%

### 6-3. 정식 학습 트랙 (별도)

세종 류대현 수석 팀의 **자체 LLM 또는 RAG/파인튜닝 트랙**은 이 문서의 알고리즘과 별개. 넘어가면 다시 논의.

## 7. 투명성 정책

사용자가 "왜 이게 추천됐는지" 볼 수 있는 수단.

### 현단계 (6/12 시연)

- 카드 하단에 "관심없음" 메뉴 제공 (부정 신호 수동 입력)
- 랜덤이 아닌 이유 가능·임 텍스트로 안내 (예: "자주 가시는 가맹점")

### 후속 라운드

- 사용자용 "내 추천 점수표" 화면 신설 검토
- 관리자 대시보드에 사용자 명별 가중치 메트릭스 추가

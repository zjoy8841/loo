v7.1 → v8.0 6가지 교정

  1. WCAG 대비 경계 — 14pt+bold (W3C 정의) → Apple 17pt 경계 + Bold any-size = 3:1
  2. Material 단계 — 3단계(thin/regular/thick) → 4단계(ultraThin 추가) + Liquid Glass 별도 functional 레이어
  3. 컬러 토큰 스키마 — 2-mode(light/dark) → 4-mode(default L/D + increased contrast L/D)
  4. hex hard-code 비권장 — Apple 공식 caveat 명문화 ("값은 OS 업데이트로 변함")
  5. 터치 타깃 — 44×44pt 기본 + 최소 28×28pt 명시 (Apple iOS 공식)
  6. safe-area 검증 — 픽셀값 검증 → env(safe-area-inset-*) / safeAreaInsets API 사용 의무화
★ Apple 공식 caveat
"Avoid hard-coding system color values in your app. Documented color values are for your reference during the app design process. The actual color values may fluctuate from release to release, based on a variety of environmental variables. Use APIs like Color to apply system colors." — developer.apple.com/design/human-interface-guidelines/color

4 · 접근성

Apple HIG 17pt 경계 · Increased Contrast · Dynamic Type AX3

v7.1의 "14pt+bold 경계"(W3C 정의) → Apple 17pt 경계로 교체. Increased Contrast 시스템 설정에 자동 추종.

4.1 — WCAG AA 대비 (Apple 공식 기준)

텍스트 크기Weight최소 대비
17 pt 이하All4.5 : 1
18 pt 이상All3 : 1
All sizesBold3 : 1
UI 컴포넌트 · 아이콘 외곽선—3 : 1
데코레이션 · 비활성—의무 없음 (시각 위계만)

출처: developer.apple.com/design/human-interface-guidelines/accessibility (fetch 2026-05-13). W3C WCAG 1.4.3는 "18pt OR 14pt+bold"를 large text 경계로 정의하지만, Apple은 17pt 컷오프 + Bold any-size = 3:1 룰을 사용. v8.0은 Apple 기준 채택.

4.3 — Dynamic Type AX3 검증

  • iOS 설정 → 손쉬운 사용 → 화면 표시 및 텍스트 크기 → 더 큰 글자 → AX3까지 홈 화면 통과
  • 회원가입 7단계 폼 라벨/플레이스홀더 잘림 없음
  • 빠른 답변 칩 멀티라인 허용 (truncate 금지)

4.4 — Reduce Motion (prefers-reduced-motion: reduce)

정지

  • 입자 영웅 자전 · 트윙클
  • Atom Voice Nav 자전 · 위성 공전 (3개 모두)
  • JARVIS 링 확장
  • 헤로 BG 비 · 구름 · 달 애니메이션

유지 (인지 도움)

  • 페이드 인/아웃
  • LIVE 점 깜박임 (≤0.5s)
  • 모드 A↔B 트랜지션 페이드

5 · 컴포넌트

v7 인벤토리 유지

v7의 컴포넌트 인벤토리(Button · TagChip · MetricCard · SceneCard · FAB · Hero Typo · BottomNav)는 v8.0에서 변경 없음. 위 토큰 레이어를 통해 의미론 토큰만 받아쓰면 됨. v7 design-guide.html § 5 ↗

마이그레이션 룰 — 컴포넌트 hex 직접 호출 제거. background: #1A1612 → background: var(--surface-elevated). color: #F5EFE6 → color: var(--ink-primary). backdrop-filter: blur(20px) → backdrop-filter: var(--material-regular).

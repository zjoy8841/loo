1 · 공통 베이스

모든 모드가 공유하는 토큰

컬러·타이포·스페이싱·아이콘·라이언 마크는 모드와 무관하게 단일 시스템. 변형은 표면 색(라이트 · 다크 · 풀블리드)에서만 일어납니다.

1.1 — 디자인 원칙

  • 차분한 따뜻함 — 채도 낮은 따뜻한 톤. 형광 · 비비드 컬러는 절제.
  • 한 화면 한 의도 — 결정 1개 또는 정보 4개 미만. 페이지 평균 스크롤 1.5회 이하.
  • 라이언이 곁에 — 라이언 캐릭터는 화면 상단·플로팅·음성 모드에 일관 배치.
  • 네이티브 앱 톤 — 카드 라운드 16-24px, 그림자 절제, 모션 짧고 부드럽게 (200-400ms).
  • 데이터는 절제 — 메트릭은 보조. 결정과 행동을 위한 1줄 인사이트 우선.

1.5 — 스페이싱 · 라운드

4의 배수 스케일: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64. 라운드: sm 8 · md 12 · lg 16 · xl 24 · 2xl 32. 휴대폰 외곽은 항상 32~38px.

1.7 — 사이버틱 시그너처 (v6.1 신설)

"AI를 의도적으로 보여준다"는 시각 약속. 모드 A·C 전반 + 로그인까지 일관 적용. 다음 5가지를 합쳐야 진짜 사이버틱:

  1. OLED 블랙 — #050505 또는 #0A0908. 따뜻한 다크(#0F0D0A)는 카드 표면에만, 베이스는 OLED.
  2. HUD 그리드 백그라운드 — 40px 격자, 라인 rgba(232,122,62,0.12), radial mask로 중앙만 보이게.
  3. 입자 영웅 메트릭 — 200-240px 구체 안에 120-180개 dot이 표면 분포 + 트윙클. 중심에 영웅 숫자.
  4. Mono 라벨 강화 — 모든 메트릭 라벨·시점 라벨·상태 표시는 mono · UPPERCASE · letter-spacing 0.1-0.18em.
  5. 단색 다크 카드 — 그라데이션 카드 절제. 단색 카드 + 1px 보더 + 단일 컬러 액센트(borderLeft 또는 dot)만.

1.7.1 — 입자 영웅 컴포넌트

WHOOP HEALTHSPAN, Oura Readiness Ring의 라이언 변형. 메인 Dashboard 상단·로그인 헤로·결과 화면 등에 단일 영웅으로 배치.

  • 크기: 모바일 220px / 데스크 320px
  • 분포: sphere point picking — 표면 균일 분포, z 시뮬레이션으로 앞쪽 입자만 밝게
  • 컬러: 베이스 dot은 --accent-honey, 5-8%만 --teal (AI 신호점)
  • 중심 숫자: 56-72px · 800 · letter-spacing -0.03em. 단위는 11px mono 라벨로 아래.
  • 회전: 60-90s 매우 느린 자전. 모션 감소 시 정지.

1.7.2 — HUD 그리드 패턴

전역 베이스가 아니라 영웅 영역·시점 영역에만 부분 적용. 마스크로 중앙만 노출해서 노이즈 줄임.

background: linear-gradient(var(--hud-line) 1px, transparent 1px), linear-gradient(90deg, var(--hud-line) 1px, transparent 1px); background-size: 40px 40px; mask: radial-gradient(ellipse at center, black 30%, transparent 75%);

v6은 "위계가 평탄하다"는 비판 받음. v6.1부터 메인 영웅과 라벨 간 최소 4배 콘트라스트 강제:

1.6 — 라이언 마크

풀컬러 / 모노 두 가지. 풀컬러는 밝은 배경에, 모노는 다크 또는 컬러풀 배경 위 색 반전용.

  • 음성 모드(자비스)에선 라이언 마크 미사용 — 자비스 링이 곧 라이언
  • 워드마크: "Life OS.ONE" 또는 "라이언"

1.8 — Cool Surface System (v7 전면 전환)

1.8.2 — Iris 액센트 (라이언 쿨 시그너처)

warm 시절 honey #E87A3E가 라이언의 따뜻함을 표현했다면, cool 시절은 Iris 계열이 라이언의 차분함을 표현. iOS Blue #007AFF와 의도적으로 차별 — indigo 잔향이 있는 보라톤 청색.

  • 라이트 surface: #5B5FE0 → #3D41C5 — 진한 indigo. Surface가 라이트일수록 액센트 진하게.
  • 다크 surface: #9094F5 → #A8AAF5 — 라이트 indigo. 어두운 베이스에서 빛남.
  • Hero eye accent: #A8AAF5 통일 — 모든 시점 hero eyebrow 라인 컬러.

1.8.4 — Atom Voice Nav (3D 자전 + 위성 공전)

음성 인터랙션 진입점이 nav 가운데 슬롯에 통합 (v7 이전 floating FAB 폐기). 시각은 3D 원자 모델 — 라이언이 핵, 위성 3개가 다른 평면에서 공전.

  • 크기 40px sphere (다른 nav-item 22px의 1.8배). translateY(-4px) 살짝 떠 nav 라인 위로 도드라짐.
  • Sphere body 5층 radial gradient — specular highlight(top-left) + rim shadow + base color. 광원 고정, sphere는 정적 입체.
  • 자전 .atom-system wrapper가 통째로 회전 (rotateZ(-12deg) rotateY(360deg), 8s 주기). 자오선·적도 wireframe이 sphere 표면을 따라 회전 → 자전 시각.
  • 위성 공전 3개 ring, 각자 rotateX(72deg) rotateY(±60deg) rotateZ(360deg)로 다른 평면 공전 (3.6s · 5s · 4.2s). wrapper 자전과 동축 — sphere가 기울면 위성 공전 평면도 함께 기움.
  • 라이언 핵 wrapper 밖 z-index 3 — 자전해도 사자 얼굴은 항상 정면. lion-breathe scale 0.93~1.0, 2.6s 호흡.
  • 위성 dot --accent 진한 색 + 0 0 0 1.5px rgba(255,255,255,0.9) white outline — 어떤 surface 위에서도 가시성 보장.

1.8.5 — 한글 Nav

v6까지 nav 라벨은 영문 mono (HOME · SCENES · COACH · YOU). 한국 시연 사용자 인지 비용 절감을 위해 v7부터 한글:

  • 홈 · 장면 · (대화 sphere) · 코치 · 나
  • 폰트: Pretendard 11px / 700 / -0.005em. mono 영문 폐기.
  • icon 22px (이전 18px) — 한글 라벨과 시각 균형.
  • 가운데 대화 sphere는 라벨 없음 — sphere 자체가 충분한 시그널.
v7 핵심 — 베이지·노란기 도는 따뜻한 surface = "오래된 카페 앱 톤" 폐기. 차분한 쿨톤 + Iris 액센트 + Atom voice nav 통합. 음성 인터랙션은 floating FAB 폐기 후 nav 가운데로 — 한 손 조작은 사용자가 nav 영역에서 모두 해결.

MODE C · CONVERSATION

JARVIS Voice — 두 화면, 한 흐름

모드 A·B의 음성 FAB을 탭하면 진입. 채팅 버블 UI는 의도적으로 피하고, 풀스크린 + 자비스 링 + 헤로 타이포만으로 대화를 표현합니다. 화면 1 → 2로 자연스럽게 흐릅니다.

화면 1 — Listening

  • 자비스 링 중앙 200px (3겹 회전 링 + 12개 오비트 도트 + 중심 글로우)
  • 그리드 노드 22개 — 약하게 떠다니며 깜빡임
  • 상단 라벨: 🎙 LION · LISTENING (teal)
  • 하단 사용자 음성 — 인식되는 텍스트가 모노스페이스로 타이핑됨
  • 데이터 태그: STT · ko-KR · 24ms

화면 2 — Responding

  • 풀스크린 이미지 — 추천한 음식·시점의 실사 (Unsplash)
  • 자비스는 하단 중앙 84px로 축소
  • 상단 라벨: ✨ LION · RESPONSE (honey)
  • 중앙 헤로 카피: "오늘은 / 보쌈 어때요?" 2-3 단어 줄바꿈, 32px, 800
  • 상단 사용자 발화 — 작게 회색으로 잔존 (대화 맥락 유지)

음성 컬러 시그널

  • Listening → Teal/Cyan (차분)
  • Thinking → Lion + Cyan + Teal + Honey conic (활동)
  • Responding → Honey + Lion (따뜻)
왜 채팅 버블이 아닌가? — 챗봇 인터페이스를 의도적으로 벗어나기 위함. 음성 대화는 시각적으로 대화가 아니라 장면이 되어야 라이언이 비서·동반자 톤으로 느껴집니다. 카카오톡 잔영을 끊는 가장 강한 신호.

6 · 보이스 톤 & 마이크로카피

라이언이 말하는 법

친근하지만 비굴하지 않게, 정보를 줄 땐 단정하게, 결정을 도울 땐 사용자에게 결정권을 남깁니다.

4 원칙

  1. 먼저 인사, 그다음 정보 — "다환님" 호명. 시간대별 인사 (아침/점심/저녁/밤).
  2. 1줄 결론 우선 — "비 와요" 같은 단정 메시지 먼저, 근거는 한 줄 아래.
  3. 제안 형식 — "~ 어때요?" "~ 챙기세요" "~ 어떠세요?". 명령형 "~하세요"는 안전 정보에만.
  4. 판단 회피 X — "건강에 좋아요"보다 "단백질 38g · 콜레스테롤 관리 페이스"처럼 근거 제시.

금지어

  • "권장합니다 / 추천드립니다" → "어떠세요?"
  • "~~ 하셔야 합니다" → "~~ 어때요?"
  • 이모지 남용 — 시점 헤로에 1개, 본문 카피엔 0개 원칙
  • 존댓말 + 반말 혼용

7 · 접근성

차분한 톤 ≠ 약한 대비

시연 청중에 40대 + 비전공자 포함. 가독성·대비·모션 제어를 베이스라인으로.

  • 색대비 — 본문 텍스트 WCAG AA 이상. 모드 B/C는 헤로 텍스트에 text-shadow: 0 2px 16px rgba(0,0,0,0.5) 필수.
  • 탭 영역 — 최소 44×44px (iOS HIG). 카드 전체를 탭 영역으로.
  • focus-visible — 모든 버튼·입력에 키보드 outline 2px Primary 500.
  • 모션 감소 — @media (prefers-reduced-motion: reduce)에서 자비스 회전·비 떨어짐·구름 드리프트 모두 정지.
  • ARIA — 음성 FAB aria-label="음성으로 라이언에게 말하기", 시점 카드 role="button".
  • 색 단독 의존 금지 — 메트릭 컬러 외에 라벨 텍스트 병기.
  • 스크린 리더 — 자비스 링은 aria-hidden="true", 상태 변화는 aria-live="polite"로 알림.
  • 음성 인식 폴백 — 실패 시 텍스트 입력 항상 가능. STT 불가 환경 안내.

8 · i18n

한국어 우선, 영어 보조

  • 기본 로케일 — ko-KR. 시연은 한국어 only.
  • 구조 — src/i18n/ko.json · en.json. 키 평탄화 (greeting.morning).
  • 변수 호명 — {name} 패턴. Pretendard는 한·영 동시 잘 지원.
  • 날짜·시간 — Intl.DateTimeFormat 사용. 시연 시 ko-KR 기본.
  • STT 언어 — ko-KR 고정. 향후 en-US 토글 검토.
  • 레이아웃 — 한·영 글자 폭 차이 고려, 헤로 카피는 2줄 줄바꿈 명시 (<br>로 디자이너 의도 고정).

01v4 → v5 변화

v4는 중앙 자비스 코어 한가운데에 라이언 마크가 박혀 있고 모든 UI 요소가 코어를 중심으로 배치. v5는 컨셉이 다름:

자비스 위치화면 한가운데 (큰)화면 하단 중앙 (작은 인디케이터)
사용자 발화하단 transcript상단 모노 텍스트 (속삭임)
AI 응답측면 panel 또는 transcript중앙 헤로 타이포 (28-36px)
채팅 bubble일부 chat-card 컴포넌트완전 제거

05대화 사이클 타임라인

한 turn = 약 8.5초. 5개 음식이 자동 순환.

t=0
Listening 시작

두 화면 모두 자비스 청록 회전. 라벨 "🎙 LION · LISTENING". 사용자 발화 영역은 비어 있고 커서만 깜빡임.

t=0.4s
사용자 발화 타이핑

"오늘 점심 뭐 먹지?" — 60ms/글자로 한 글자씩 추가. 두 화면 동시. 화면 1=중앙 하단, 화면 2=상단.

t=2~3s
Thinking + 점 3개

발화 끝 → 600ms 후 라벨이 "⚙ ANALYZING"으로 변하고 자비스 코어가 conic 그라데이션 회전 시작. 화면 2 중앙에 점 3개 indicator 표시 (1.5초).

t=4~5s
응답 — 이미지 + 헤로

라벨 "✨ RESPONSE", 자비스 코어 호박빛 변환. 화면 2 음식 이미지 풀스크린 fade-in (0.8s) + 중앙 헤로 텍스트 fade-up. "오늘은 보쌈 어때요?"

t=8s
Fade-out

이미지·텍스트·사용자 발화 모두 fade-out. 자비스만 남음 (계속 회전).

t=8.7s
다음 turn

다음 음식 + 발화로 사이클 재시작. 직전 대화만 표시되고 누적 없음.

06자비스 위치 변화 — Center → Bottom-Center

두 화면 모두 자비스는 회전 중. Screen 1은 화면 중앙(220×220 큰 사이즈), Screen 2는 화면 하단 중앙(88×88 작은 사이즈).

/* Screen 1: 중앙 큰 자비스 */
.jarvis.center {
  top: 50%; left: 50%;
  width: 220px; height: 220px;
  margin-top: -110px; margin-left: -110px;
}

/* Screen 2: 하단 중앙 작은 자비스 */
.jarvis.bottom-center {
  bottom: 56px; left: 50%;
  width: 88px; height: 88px;
  margin-left: -44px;
}

07시각 계층 — 단 3층 (채팅 bubble 없음)

화면 위에 오버레이된 텍스트는 정확히 3층. bubble·테두리·배경 없음.

층요소스타일
L1상단 라벨 (RESPONSE)11px uppercase, letter-spacing 0.18em, mono
L2사용자 발화13px mono, opacity 0.7, 따옴표, 작게
L3 ★AI 응답 헤로28~36px weight 800, 흰색, text-shadow, 중앙

L3가 화면의 주인공. 배경 이미지가 맥락을 직관 전달하고, 헤로 텍스트가 한 줄 답.

사용자 발화 타이핑

// 60ms/글자, 커서 깜빡임
function typeText(target, text) {
  let i = 0;
  const id = setInterval(() => {
    if (i < text.length) {
      target.innerHTML = text.slice(0, i+1) + '<span class="cursor"></span>';
      i++;
    } else clearInterval(id);
  }, 60);
}

09체크리스트

  • 채팅 bubble (배경·테두리·말풍선)이 없는가?
  • Screen 1은 자비스 중앙 + 사용자 발화 하단?
  • Screen 2는 음식 이미지 풀스크린 + 헤로 중앙 + 자비스 하단 중앙?
  • 두 화면이 같은 대화 turn을 동기로 진행?
  • 사용자 발화 타이핑 효과 (커서 깜빡임)?
  • Thinking 단계에 점 3개 indicator (1.5s)?
  • 응답 시 이미지 fade-in (0.8s) + 헤로 텍스트 fade-up?
  • 자비스 상태별 코어 색 변환 (청록 → conic → 호박빛)?
  • 한 turn 약 8.5s, 자동 순환, 누적 X (직전 대화만)?
  • 다크 그라데이션 오버레이로 가독성 ≥ 11:1?
  • reduced-motion 대응?

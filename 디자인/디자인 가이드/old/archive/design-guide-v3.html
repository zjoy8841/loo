시점 시나리오 UI

시점 화면(아침·점심·저녁·취침)은 카드·UI 요소 대신 실사 배경 풀 화면으로. "비가 온다" "음식이 있다" "노을이 진다"를 직관적으로 보여주고, 텍스트는 단 2층 (헤로 + 메타) 만 노출. Frame 2 영감.

v3 (Immersive · 시점 시나리오용)

  • 풀 화면 실사 배경
  • UI 요소 최소화 (텍스트 2층만)
  • 맥락 직관 (비·햇살·노을·음식)
  • 정서 우선
  • → 아침·점심·저녁·취침 시점 화면

03시각 계층 — 단 3층

풀 화면 UI의 핵심은 최소 요소 · 최대 임팩트. 화면 위에 텍스트는 3층만 노출.

①

Moment Label (상단 11px)

"🌅 Morning" · "🍱 Lunch" — 시점 명시. uppercase letter-spacing 0.15em. opacity 0.75. 작고 절제됨.

②

Hero Text (28~32px, weight 800)

핵심 액션·메시지. 2줄 최대. text-shadow로 가독성 보호. "자켓·우산 꼭 챙기세요."

③

Meta Bottom (13px, 아이콘 + 텍스트)

맥락 정보. 2~3줄. 각 줄: 아이콘(이모지 또는 SVG) + 텍스트. 핵심 숫자·키워드만 bold.

04그라데이션 오버레이 — 가독성 보호

실사 이미지는 밝기·대비가 일정하지 않음. 어떤 사진이 와도 텍스트 가독성을 위해 상하 다크 그라데이션 오버레이.

/* 풀 화면 시점 배경 위 가독성 보호 오버레이 */
.screen-overlay {
  position: absolute;
  inset: 0;
  background: linear-gradient(
    180deg,
    rgba(0,0,0,0.55) 0%,    /* 상단: 헤로 텍스트 영역 */
    transparent      30%,
    transparent      55%,
    rgba(0,0,0,0.85) 100%   /* 하단: 메타 + FAB 영역 */
  );
}
  • 상단 0~30%: 어두운 그라데이션 (헤로 흰 텍스트 대비)
  • 중앙 30~55%: 투명 (배경 그대로 노출)
  • 하단 55~100%: 강한 어두움 (메타·FAB 가독성)

05배경 가이드 — 시점별 이미지·분위기

실서비스에서는 실사 사진 사용. 시연 단계에서는 CSS 그라데이션+패턴으로 분위기만 표현.

06인터랙션 + 모션 표현

화면은 정지 사진이 아니라 살아있는 장면. 비가 실제로 내리고, 햇살이 펄스하고, 별이 깜빡임. 동영상이 아닌 CSS 애니메이션 + JS 파티클로 가벼우면서 인터랙티브.

핵심 코드 패턴 (CSS + JS 파티클)

/* 비 한 줄 */
.drop {
  position: absolute;
  width: 1px;
  background: linear-gradient(180deg, transparent, rgba(220,235,250,0.9));
  animation: drop-fall linear infinite;
  will-change: transform;
  /* will-change로 GPU 레이어 생성 → 60fps 안정 */
}
@keyframes drop-fall {
  0%   { transform: translate3d(0, -120px, 0); }
  100% { transform: translate3d(-30px, 110vh, 0); } /* 사선 (좌하향) */
}

/* JS로 140개 생성, random 속성 */
for (let i = 0; i < 140; i++) {
  const d = document.createElement('div');
  d.className = 'drop';
  d.style.left = Math.random() * 110 + '%';
  d.style.height = (30 + Math.random()*50) + 'px';
  d.style.animationDuration = (0.5 + Math.random()*0.6) + 's';
  d.style.animationDelay = -Math.random()*1.5 + 's';  /* 음수 delay = 즉시 시작 분산 */
  d.style.transform = 'rotate(15deg)';
  rainLayer.appendChild(d);
}

성능·배터리 가이드

  • 파티클 수 모바일 ≤ 150개, 데스크탑 ≤ 300개
  • will-change: transform으로 GPU 레이어 강제
  • 화면 밖 (시점 비활성) 시 애니메이션 일시정지 — animation-play-state: paused
  • prefers-reduced-motion 대응 — 모든 애니메이션 끔
  • backdrop-blur는 모바일에서 무거움 → FAB 한 곳만 사용
  • background에 image-set + loading="lazy" 로 실사 사진 lazy load

07컴포넌트 in Full-bleed

풀 화면 위에 떠 있는 컴포넌트는 반투명 + backdrop-blur로 처리. 화면을 가리지 않고 배경과 조화.

FAB (반투명 흰색)

background: rgba(255,255,255,0.95) + backdrop-filter: blur(8px)

하단 dots indicator

현재 시점 위치. 4개 (아침·점심·저녁·취침) 또는 3개 (취침 제외).

모달·시트 (탭 시 펼침)

바텀 시트 형태. bg-elevated 베이스. 풀 화면 위 80% 높이까지 올라오는 sheet.

10체크리스트

  • 풀 화면 실사 배경이 사용되었는가? (UI 요소가 화면을 차지하지 않음)
  • 다크 그라데이션 오버레이로 가독성 보호?
  • 텍스트 계층 3층만 사용? (moment label · hero · meta)
  • 맥락이 직관적으로 전달되는가? (비=비 사진, 음식=음식 사진)
  • 헤로 텍스트는 2줄 이하인가?
  • 메타는 2~3줄에 아이콘+텍스트 패턴?
  • FAB는 반투명+blur로 배경과 조화?
  • 스와이프·탭 인터랙션이 동작하는가?
  • reduced-motion에서 배경 애니메이션 끔?
  • 라이언 톤의 마이크로카피?

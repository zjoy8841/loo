라이언 — 로그인 Orb 6 시안

[ ANIMATION VARIANTS · 2026-05-12 ]

v7 로그인 화면 앞단의 라이언 원형 이미지 애니메이션을 6가지 다른 컨셉으로 분리. 실제로 보면서 톤을 비교해보고 선택할 수 있도록.

V1

Cosmic Halo CURRENT V7

현재 v7 톤. 3겹 회전 ring(dotted/solid/dashed) + 입자 80개 + ambient glow 호흡 + 라이언 좌우 갸웃. 차분하고 신비로움. AI라기보다 라이프 OS의 따뜻한 입구.

V2

Liquid Blob VISION PRO · CHATGPT

외곽이 부드러운 유체처럼 천천히 변형. border-radius keyframe으로 8s 사이클. 가장 AI스러운 톤. Vision Pro Siri sphere · ChatGPT 음성 모드 영감.

V3

Pulse Wave SIRI · APPLE WATCH

중심에서 외곽으로 ring 4겹이 0.6s 간격 연속 발산. 라이언 코어는 호흡. 활발하고 응답성 있는 톤. 음성 인식 직전 같은 느낌. Siri 음파 영감.

V4

Iris Bloom DYNAMIC ISLAND · DUOLINGO

꽃잎/홍채 8장이 천천히 회전(18s) + 각자 4s 호흡. 유기적이고 친근. 캐릭터(사자)와 잘 어울리는 보조 시각. Duolingo·Dynamic Island 영감.

V5

Particle Storm APPLE MUSIC · NOTHING OS

입자가 코어 주위를 다양한 반경(50-75px)으로 공전(2-5s). 외곽 ring 3겹도 다른 속도로 회전. 역동적·기술적. AI 활성 시그널 강함. Apple Music visualizer · Nothing OS dot.

V6

Mesh Aurora VISION PRO · LINEAR · STRIPE

sphere 안에 4색 mesh gradient(teal·iris·honey·accent)가 흐름(8s). blur 20px + 자전 + scale 호흡. 고급스럽고 모던. Linear·Stripe 결제·Vision Pro 라이센스.

v3 CSS vs v4 Spline — 본질적 차이

v3의 Mesh Aurora가 CSS로는 가장 정교했지만, 결국 2D 그라데이션의 시각적 트릭이에요. v4는 진짜 3D 메시·법선·반사·셰이더가 매 프레임 계산됩니다. v3 변형들 다시 보기 → 한 화면에 띄워두고 비교하시면 차이가 즉각 보입니다.

실제 Next.js 앱에 적용하는 법 (lifeosone/web)

# 1) 패키지 설치
npm install @splinetool/react-spline @splinetool/runtime

// 2) 로그인 페이지 컴포넌트
import Spline from '@splinetool/react-spline/next';

export default function LoginBackground() {
  return (
    <Spline
      scene="https://prod.spline.design/UVPewD9fAjoKeeMh/scene.splinecode"
      style={{ position: 'absolute', inset: 0, zIndex: 0 }}
    />
  );
}
  • 로딩 최적화: `next/dynamic`로 lazy load 권장 (씬 파일 1~3MB)
  • 모바일 성능: 저사양 기기는 WebGL 부담 → `prefers-reduced-motion` 감지 시 정적 이미지로 폴백
  • 레이어 순서: Spline은 절대 위치 z:0, 로그인 폼은 z:10 이상으로 띄우기
  • 색 톤 매칭: 현재 씬은 검정 베이스 — 라이언 v6 다크 톤과 잘 맞음. 라이트 모드면 다른 씬 필요

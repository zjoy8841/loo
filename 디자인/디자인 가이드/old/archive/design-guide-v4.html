01실제 데모 — 5가지 상태 전환

하단 5개 버튼 또는 키보드 1~5로 상태 전환. 음성 입력의 전체 생애주기를 한 화면에서 본다.

위 iframe이 잘 안 보이면 ▶️ 새 탭에서 열기.

025가지 상태

음성 입력의 전체 생애주기. 각 상태마다 시각·텍스트가 모두 변화.

STATE 1
🌙

Idle (대기)

코어 호흡만, 펄스·waveform 정지. 호출 대기 안내.

STATE 2
📡

Calling (호출 감지)

"라이언아" 감지. 동심원 펄스 시작, 링 가속.

STATE 3
🎙

Listening (입력)

STT 활성. waveform 막대 활기, 코어 청록으로 변환.

STATE 4
⚙

Thinking (분석)

코어 conic 그라데이션 회전. 측면 데이터 흐름 빨라짐.

STATE 5
✨

Responding (응답)

코어 호박빛 글로우 강화. 결과 카드 페이드인.

03시각 레이어 — 8개 층

홀로그래픽 효과는 단일 SVG가 아닌 여러 CSS 레이어 합성으로 만든다. 각 레이어는 단순하지만 합쳐지면 자비스 느낌.

L1 · 배경 HUD 그리드

60×60 px 청록 라인. radial mask로 가장자리 fade.

linear-gradient + background-size + mask-image

L2 · 떠다니는 노드 40개

constellation. 청록 dots, glow shadow, float + twinkle 애니메이션.

JS 동적 생성 · keyframes float, twinkle

L3 · 외곽 회전 링 3개

속도·방향·색 다른 3개 (8s/12s 역방향/6s). 부분 호 (border 일부만).

border-color 부분 + animation: spin

L4 · 60개 tick 눈금

시계 눈금 같은 디테일. 5의 배수는 더 길게.

JS 60개 생성, transform-origin rotate

L5 · orbit 점 6개

중간 ring 안 6개 점이 회전.

cos/sin 계산 + animation: spin 16s

L6 · 동심원 펄스 3겹

코어에서 바깥으로 확장. 0.6s 간격으로 계속.

keyframes pulse-out: scale 1→3 + opacity 1→0

L7 · 중앙 코어 (라이언 마크)

호박빛 글로우 + 호흡 (scale 1↔1.04). 상태별 색·애니메이션 변경.

radial-gradient + box-shadow glow + core-breathe

L8 · waveform 32개 막대

음성 입력 시 활기. 막대마다 random duration·delay.

JS bars + keyframes wave-bounce

06타이핑 효과 — transcript

사용자가 말하는 동안 화면 하단에 실시간 STT 결과가 타이핑되듯 한 글자씩 표시. 커서 깜빡임.

/* 핵심 JS */
function typeText(el, text, speed = 50) {
  el.textContent = '';
  let i = 0;
  const timer = setInterval(() => {
    if (i < text.length) el.textContent += text[i++];
    else clearInterval(timer);
  }, speed);
}

/* CSS 커서 */
.transcript::after {
  content: '|';
  animation: cursor 1s steps(1) infinite;
  color: var(--teal);
}
@keyframes cursor { 50% { opacity: 0; } }

08성능 가이드

  • 레이어 8개지만 모두 CSS·SVG → 총 50KB 미만, 60fps 안정
  • nodes·waveform 모두 will-change: transform 또는 will-change: height 명시
  • 화면 비활성 시 (탭 백그라운드) document.hidden으로 애니메이션 일시정지
  • 모바일에서 측면 데이터 패널 자동 숨김
  • prefers-reduced-motion 시 모든 애니메이션 0.01ms로
  • backdrop-blur는 컨트롤 바 한 곳만 (모바일 부담)
  • 음성 인식 실패 시 graceful fallback — 화면 끄지 말고 "다시 한 번..." 안내

# 말하는 데이지 (talk)

대화 중 상태. 메인 idle 모드에서 사용자와 대화 시작 / 응답 / 설명할 때.

## 공통 prefix (매 생성마다 앞에 붙임)

```
Same character as reference. Same pink hair, same pink dress with lace details,
same face proportions, same skin tone. Waist-up portrait, soft blurred background,
front-facing camera angle. Pixar 3D render style, soft lighting.
```

> 첫 생성엔 `데이지.png` 또는 `데이지 상반신.png`를 reference로.
> 같은 폴더 안에서 변형 만들 땐 `v1.png`를 reference로 넣으면 일관성이 더 강해짐.

---

## v1 — 기본 (현재 파일: v1.png)

```
Mouth slightly open as if speaking, friendly expression, eyes looking at viewer,
one hand raised near chest in a gentle gesture, mid-conversation pose.
```

## v2 — 적극적 설명 (양손 제스처)

```
Mouth open speaking energetically, both hands raised at chest level palms forward
as if explaining an idea, bright engaged expression, slight forward lean,
expressive eyebrows, animated mid-explanation pose.
```

## v3 — 경청 후 응답 (고개 기울임)

```
Slight smile with mouth gently parted as if mid-reply, head tilted to one side
attentively, one hand touching her own collar lightly, the other relaxed at side,
warm conversational expression, focused eye contact with viewer.
```

## v4 — 이야기 풀어내기 (스토리텔링)

```
Lively storytelling pose, mouth open with a soft smile, one hand sweeping
outward to the side as if describing something exciting, sparkling eyes,
eyebrows slightly raised in animation, expressive and warm.
```

# 놀라는 데이지 (surprise)

놀람·발견·신기함. 예상치 못한 알림 / 새로운 기능 발견 / 사용자가 놀랄만한 데이터 발견 시.

## 공통 prefix (매 생성마다 앞에 붙임)

```
Same character as reference. Same pink hair, same pink dress with lace details,
same face proportions, same skin tone. Waist-up portrait, soft blurred background,
front-facing camera angle. Pixar 3D render style, soft lighting.
```

> 첫 생성엔 `데이지.png` 또는 `데이지 상반신.png`를 reference로.
> 같은 폴더 안에서 변형 만들 땐 `v1.png`를 reference로 넣으면 일관성이 더 강해짐.

## v1 — 기본 (현재 파일: v1.png)

```
Eyes wide open in pleasant surprise, mouth small "o" shape,
eyebrows raised, one hand near mouth, slight head pull back.
```

## v2 — 양손 가스프 (gasping)

```
Gasping in pleasant surprise, both hands raised to either side of her face,
eyes wide open with sparkle, mouth in a wider "o" shape,
eyebrows lifted high, light delighted shock.
```

## v3 — 발견 (discovery, 앞으로 기울임)

```
Wide-eyed wonder, leaning slightly forward toward viewer, mouth open in a small
gasp, one hand reaching forward as if to point at something amazing,
expression of curious astonishment, bright lit-up eyes.
```

## v4 — 스파클 감탄 (stars-in-eyes)

```
Stars-in-eyes amazement, mouth open in delighted surprise, both hands clasped
near her chest holding her breath, slight pull-back posture,
sparkles or stars implied in her eyes, charming wonder.
```

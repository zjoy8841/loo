# Figma Make 프롬프트 — 메인 화면 A·B

> **용도**: Figma Make에 붙여넣어 메인 화면 2분기(A 대화 입구 · B 브리핑 피드)를 생성.
> **운전**: 오다환 (Figma 제품 안에서 직접). Claude Code는 결과를 Figma MCP로 읽어 검수·`web/` 통합.
> **방식**: 아래 "① 공통 시스템 블록"을 먼저 복사 → "②-A" 또는 "②-B" 프롬프트 끝에 이어붙여 한 번에 입력. A와 B는 **각각 별도 생성**으로 돌릴 것.
> **반복**: 첫 출력이 어긋나면 "더 멋지게" 대신 구체 피드백 — "히어로 절반으로", "악센트는 1곳만", "카드 테두리 빼고 여백으로 묶어".
> **기준 문서**: 디자인 가이드 v8.0 + 부록 §composition·§exemplars. 출력은 §composition C.5 체크리스트로 검수.

## ① 공통 시스템 블록 (A·B 둘 다 앞에 붙임)

```
[제품 맥락]
"Life OS.ONE" — 개인화 AI 라이프 어시스턴트 모바일 앱(iOS). AI 비서의 이름은 "라이언"이고
사자 마스코트로 의인화된다. 앱은 가입 시 사용자의 건강·체형·식이·라이프스타일·직업·관심사를
받아 모든 추천을 개인화한다. 지금 만들 화면은 앱의 메인(홈) 화면이다.

[디바이스 / 언어]
iPhone 14 Pro, 393×852pt 세로. UI 언어는 한국어. 폰트는 Pretendard.

[비주얼 시스템 — 반드시 준수]
- 시점: "아침" 톤. 배경은 차분한 블루그레이 #F4F6FA, 카드는 흰색, 텍스트는
  #0F1419(주) / #5A6372(보조) / #8A93A3(약). 악센트는 인디고 "Lion Iris" #5B5FE0 단 하나.
- 타입: Apple HIG Dynamic Type 스케일. 한 화면에 글자 크기 3종 이하, 위계는 "크게 점프"로만.
- 간격: 8pt 그리드. 섹션↔섹션은 넓게, 그룹 내부는 좁게 — 이 리듬을 화면 전체에서 일관 유지.
- 아이콘: 이모지 절대 금지. 가늘고 일관된 라인 아이콘 세트만 사용.
- 하단 내비게이션: 5칸. 한글 라벨 "홈 · 장면 · (라이언) · 코치 · 나". 가운데 칸은
  은은하게 빛나는 구체(AI 라이언)로, 다른 4칸보다 살짝 위로 솟음.

[디자인 원칙 — 어기면 실패]
1. 한 화면에 시선의 초점은 정확히 1개. 가장 크고 가장 진하고, 악센트는 그 1개에만.
2. 카드에 테두리(border)를 두르지 말 것. 관련 항목은 ① 여백 ② 옅은 면(soft-fill) ③ 얇은
   구분선 순서로 묶는다. 카드마다 테두리 = 실패.
3. 그림자 깊이는 1단계만. 화면에서 떠 있는 요소는 "초점" 1개뿐, 나머지는 평평하게.
4. 채워진 강조 버튼은 화면당 1개. 장식용 그라데이션·글로우도 화면당 1개(보통 초점).
5. 풀블리드: 배경은 화면 끝까지, 스크롤 콘텐츠는 하단 내비 "뒤로" 흘러간다. 버튼은
   화면 가장자리에서 좌우 20pt 안쪽으로.
6. 더미·이모지 말고 아래 [실제 콘텐츠]로 채울 것.

[톤 & 레퍼런스]
차분하고 에디토리얼하며 프리미엄한 느낌. Headspace의 따뜻함 + Linear의 절제와 위계 +
Granola의 조용한 에디토리얼 감각.
안티-레퍼런스: 지표가 빽빽한 대시보드 아님. 썸네일이 줄줄이 박힌 뉴스 앱 피드 아님.
정보 밀도보다 "오늘 가장 중요한 것 하나"가 숨 쉴 공간이 우선.
```

## ②-A 프롬프트 — Ⓐ AI 비서 대화 입구

```
[이 화면의 단 하나의 역할]
메인 = "라이언과 대화를 시작하는 곳". 정보는 최소로, 나머지는 대화로 끌어낸다.
화면의 초점은 라이언 마스코트 자체.

[레이아웃 — 위에서 아래로]
1. 인사 줄: 작은 라이언 마스코트 원형 아이콘 + "다하님, 좋은 아침이에요" +
   아래 작게 "함께한 47일 · 수요일". 배경 위에 직접, 카드 없음.
2. 히어로(화면의 초점, 세로 가운데 넉넉한 여백): 큰 라이언 마스코트 구체.
   둘레에 은은한 인디고 글로우와 가는 링 1~2개(이 화면의 유일한 장식 그라데이션).
   구체 아래에 작은 라벨 "오늘, 무엇을 도와드릴까요" + 그 아래 한 문장:
   "비 80%에 강남 미팅 있는 날이에요. 우산이랑 트렌치, 제가 챙길게요."
   ("80%"만 악센트 인디고).
3. 추천 질문 칩 3개(세로 스택, 옅은 면, 테두리 없음, 명백히 보조 무게):
   "오늘 점심 뭐 먹는 게 좋을까?" / "10시 미팅 자료 정리해줘" / "이번 주 일정 한눈에 보여줘".
   각 칩 오른쪽 끝에 작은 화살표.
4. 정보 핀: 하나의 옅은 면 컨테이너 안에 2칸을 가는 세로 구분선으로 나눔.
   왼쪽 "오늘 날씨 — 비 80% · 우산", 오른쪽 "다음 일정 — 10:00 미팅". 각 칸 작은 아이콘.
5. 채팅 입력 바(화면 하단 고정, 흰색, 부드러운 그림자만, 테두리 없음 — 화면에서
   유일하게 떠 있는 요소): 플레이스홀더 "라이언에게 말 걸기" + 음성 버튼 + 보내기 버튼.
6. 하단 내비게이션(공통 블록 참조), "홈" 활성.

[제약 재확인]
초점은 라이언 구체 1개. 채워진 강조 = 보내기 버튼 1개. 칩·핀은 테두리 없이 여백·옅은
면으로만 묶을 것. 첫 화면 안에 다 들어오게(스크롤 없이).
```

(앞에 "① 공통 시스템 블록"을 붙여서 함께 입력)

## ②-B 프롬프트 — Ⓑ 데일리 브리핑 피드

```
[이 화면의 단 하나의 역할]
메인 = "오늘 하루치 정보를 한 번에 훑는 곳". 대화는 하단 내비 구체로 부차.
화면의 초점은 맨 위 "오늘의 브리핑" 카드.

[레이아웃 — 위에서 아래로, 세로 스크롤]
1. 인사 헤더: "다하님, 좋은 아침이에요"(두 줄, 이 화면에서 가장 큰 글자) +
   아래 작게 "2026년 5월 14일 · 수요일". 배경 위에 직접.
2. 오늘의 브리핑 카드(화면의 초점 — 유일하게 떠 있고 유일한 그라데이션):
   인디고 그라데이션 배경, 흰 글자. 작은 라이언 아바타 + 라벨 "오늘의 브리핑".
   본문 한 문단: "오늘은 비 80%에 10시 강남 미팅이 있어요. 수면 7시간 12분으로
   컨디션은 충분하니, 우산만 챙기면 든든한 하루예요."
   아래 작은 통계 3칸: 날씨 "비·14°" / 강수 "80%" / 수면 "7h 12m".
3. 섹션 "오늘의 헤드라인"(작은 라벨 + 오른쪽에 "관심사 기반"):
   썸네일·카드 없는 에디토리얼 리스트 3줄, 줄 사이는 얇은 구분선으로만.
   각 줄 = 작은 카테고리 라벨 + 헤드라인 + 출처·시각.
   · 증시 — "코스피 2,890 (-1.2%) · 호르무즈 긴장에 유가 5% 상승" — 매일경제·28분 전
   · IT·테크 — "Anthropic Claude 5 출시 임박 '추론·코드 30% 향상'" — 디지털타임스·3시간 전
   · 자기계발 — "'하루 30분 독서 챌린지' 직장인 1만 명 신청" — 동아일보·어제
   (첫 줄 카테고리만 악센트, 나머지는 회색)
4. 섹션 "오늘의 점심"(라벨 + "페르소나 기반"): 단일 추천 1개를 옅은 면 행으로.
   왼쪽 작은 음식 아이콘 + "미팅 많은 날·단백질"(작은 악센트 라벨) + "닭가슴살 샐러드" +
   "B카페 · 4.7★ · 도보 3분". 행 전체가 탭 타깃 — 별도 버튼 없음.
5. 섹션 "오늘의 미션"(라벨 + "1 / 3 완료"): 옅은 면 컨테이너 1개 안에
   진행 바 + 항목 3개. "아침 브리핑 확인"(완료, 취소선) / "물 8잔 마시기"(3/8) /
   "저염 메뉴 1번 선택".
6. 하단 내비게이션(공통 블록 참조), "홈" 활성.

[제약 재확인]
초점은 브리핑 카드 1개 — 그 아래 섹션들은 전부 평평하고 조용하게(테두리·그림자 없음,
옅은 면 또는 구분선으로만 그룹). 뉴스에 썸네일·이모지 금지. 장식 그라데이션은 브리핑 카드뿐.
```

(앞에 "① 공통 시스템 블록"을 붙여서 함께 입력)

## ③ 출력 후 — Claude Code 검수 체크리스트 (§composition C.5)

Figma Make 결과가 나오면 아래로 채점(Claude Code가 Figma MCP로 읽어 수행 가능):

- [ ] 초점이 정확히 1개인가 (A=라이언 구체 / B=브리핑 카드)
- [ ] 글자 크기 3종 이하, 인접 단계 동시 사용 없음
- [ ] 악센트 인디고가 시선 유도 1개 요소에만
- [ ] 모든 간격이 8pt 배수인가
- [ ] 카드 테두리 0 — 여백·옅은 면·구분선으로만 그룹핑
- [ ] 그림자 1단계, 채워진 버튼 1개, 장식 그라데이션 1개
- [ ] 이모지 0 — 일관된 라인 아이콘만
- [ ] 배경·스크롤이 화면 끝까지, 하단 내비는 콘텐츠 위에 뜸
- [ ] 더미 아닌 실제 콘텐츠로 채워졌는가

검수 통과 후 → A/B 방향 결정 → 선택안을 Figma SSoT로 확정 → `web/` 통합.

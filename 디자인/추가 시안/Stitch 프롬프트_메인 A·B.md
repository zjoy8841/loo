# Google Stitch 프롬프트 — 메인 화면 A·B

> **용도**: Google Stitch(stitch.withgoogle.com)에 붙여넣어 메인 화면을 생성.
> **운전**: 오다환이 Stitch에서 직접 (무료, 월 350회 생성). Claude Code는 MCP로 Stitch 제어 불가.
> **방식**: 아래 "① 공통 컨텍스트"를 복사 → "②-A" 또는 "②-B" 뒤에 이어붙여 한 번에 입력.
> A와 B는 **각각 별도 생성**으로 돌려서 비교.
> **반복**: 첫 결과가 어긋나면 새로 생성하지 말고 대화형으로 수정 — "히어로를 더 크게",
> "악센트 색을 하나만", "카드 테두리 빼고 여백으로" 같은 구체 지시.
> **다음 단계**: 마음에 드는 결과 → HTML/CSS export 또는 Figma 복붙 → Claude Code가 `web/` 통합.

> **왜 이렇게 자세한가**: 리서치 결론 — AI 디자인 도구는 방향을 안 주면 generic하게 나온다.
> 강한 비주얼 디렉션을 줄수록 "진짜 디자이너가 아트디렉션한 것"에 가까워진다.
> 단, 정확한 hex·픽셀까지 박지는 말 것 — 그건 Stitch(디자이너 역할)의 몫. 우리는
> 맥락·위계·콘텐츠·"하지 말 것"을 강하게, 수치는 느슨하게.

## ① 공통 컨텍스트 (A·B 둘 다 앞에 붙임)

```
[제품]
"Life OS.ONE" — 개인화 AI 라이프 어시스턴트 모바일 앱(iOS). AI 비서는 "라이언"이라는
친근한 사자 캐릭터로 의인화된다. 앱은 가입 시 사용자의 건강·식이·라이프스타일·직업·관심사를
받아 모든 추천을 개인화한다. 지금 만들 화면은 앱의 메인(홈) 화면이다.

[플랫폼 / 언어]
iPhone, 세로. UI 언어는 한국어.

[비주얼 방향 — 강하게 따를 것]
- 톤: 차분하고 에디토리얼하며 따뜻하고 프리미엄한 느낌. 이른 아침 시간대의 공기.
- 레퍼런스 감각: Headspace의 따뜻함 + Linear의 절제와 위계 + Granola의 조용한 에디토리얼.
- 색: 차분한 라이트 배경 + 절제된 악센트 1색. 악센트는 "다음에 볼 곳"을 가리키는 1개 요소에만.
- 위계: 한 화면에 시선의 초점은 정확히 1개. 큰 글자 크기는 3종 이하, 위계는 크게 점프시켜 표현.
- 여백: 넉넉하게. 관련 항목은 여백으로 묶고, 카드를 테두리로 줄줄이 두르지 말 것.
- 풀블리드: 배경·헤더가 화면 끝까지. 하단 내비게이션은 콘텐츠 위에 떠 있게.
- 라이언 마스코트: 친근한 사자 캐릭터를 일러스트로 표현. AI 비서의 정체성을 드러내는 요소.

[절대 아님 — anti-reference]
- 지표가 빽빽한 대시보드
- 흔한 부트스트랩/템플릿 룩
- 어두운 sci-fi 톤
- 이모지를 아이콘으로 쓰는 것
- 정보 조각마다 테두리 카드로 감싸는 것

[하단 내비게이션]
5칸. 가운데 칸은 AI(라이언) 호출 버튼으로 다른 칸보다 살짝 위로 솟음.
라벨: 홈 · 장면 · 라이언 · 코치 · 나.
```

## ②-A 프롬프트 — Ⓐ AI 비서 대화 입구

```
[이 화면의 단 하나의 역할]
메인 = 사용자가 라이언과 대화를 시작하는 곳. 정보는 최소한으로, 나머지는 대화로 끌어낸다.
화면의 초점 = 라이언 캐릭터 자체.

[레이아웃 — 위에서 아래로, 스크롤 없이 한 화면]
1. 인사: "다환님, 좋은 아침이에요" + 그 아래 작게 "함께한 47일 · 수요일"
2. 히어로(화면 중앙, 넉넉한 여백): 라이언 사자 캐릭터 일러스트가 크게, 살아있는 느낌으로
   (은은한 빛 또는 숨 쉬는 듯한 분위기). 캐릭터 아래에 한 문장:
   "비 80%에 강남 미팅 있는 날이에요. 우산이랑 트렌치, 제가 챙길게요."
3. 추천 질문 칩 3개(세로 스택, 조용한 무게 — 명백히 보조):
   "오늘 점심 뭐 먹는 게 좋을까?" / "10시 미팅 자료 정리해줘" / "이번 주 일정 한눈에 보여줘"
4. 오늘 꼭 봐야 할 것 2개만(작게, 미니멀): 날씨 "비 80%" / 다음 일정 "10:00 강남 미팅"
5. 화면 하단 고정: 라이언에게 말 거는 입력 바 (텍스트 입력 + 음성 버튼)
6. 하단 내비게이션 (공통 컨텍스트 참조)

[강조]
초점은 라이언 캐릭터 1개. 채워진 강조 버튼은 입력 바의 전송 1개만. 정보는 2개로 압축.
```

(앞에 "① 공통 컨텍스트"를 붙여서 함께 입력)

## ②-B 프롬프트 — Ⓑ 데일리 브리핑 피드

```
[이 화면의 단 하나의 역할]
메인 = 오늘 하루치 개인화 정보를 한 번에 훑는 곳. 대화는 하단 내비 라이언 버튼으로 부차.
화면의 초점 = 맨 위 "오늘의 브리핑" 카드.

[레이아웃 — 위에서 아래로, 세로 스크롤]
1. 인사 + 날짜: "다환님, 좋은 아침이에요" / 작게 "2026년 5월 14일 · 수요일"
2. 오늘의 브리핑 카드(화면의 초점 — 가장 눈에 띄게): 라이언이 날씨·일정·컨디션을
   한 문단으로 요약 — "오늘은 비 80%에 10시 강남 미팅이 있어요. 수면 7시간 12분으로
   컨디션은 충분하니, 우산만 챙기면 든든한 하루예요." + 작은 통계 3개(날씨 비·14° /
   강수 80% / 수면 7h 12m). 작은 라이언 아바타 포함.
3. 오늘의 헤드라인 3개(관심사 기반 — 썸네일 없는 조용한 에디토리얼 리스트, 줄 사이 얇은 구분선):
   · 증시 — "코스피 2,890 (-1.2%) · 호르무즈 긴장에 유가 5% 상승" — 매일경제 28분 전
   · IT·테크 — "Anthropic Claude 5 출시 임박, 추론·코드 30% 향상" — 디지털타임스 3시간 전
   · 자기계발 — "하루 30분 독서 챌린지, 직장인 1만 명 신청" — 동아일보 어제
4. 오늘의 점심(페르소나 기반 추천 1개): "닭가슴살 샐러드" · B카페 · 4.7★ · 도보 3분.
   "미팅 많은 날 · 단백질" 같은 추천 이유 라벨.
5. 오늘의 미션(압축): 진행바 + 항목 3개 — "아침 브리핑 확인"(완료) / "물 8잔 마시기"(3/8) /
   "저염 메뉴 1번 선택"
6. 하단 내비게이션 (공통 컨텍스트 참조)

[강조]
초점은 브리핑 카드 1개 — 그 아래 섹션들은 전부 조용하고 평평하게. 헤드라인에 썸네일 금지.
```

(앞에 "① 공통 컨텍스트"를 붙여서 함께 입력)

## ③ 반복(iteration) 팁

Stitch는 대화형 수정이 강점 — 첫 결과가 80%면 새로 생성하지 말고 고쳐나간다:

- 막연한 "더 멋지게" 금지. 구체적으로: "히어로를 화면의 절반 크기로", "악센트 색을 하나만
  남기고 나머지는 회색으로", "카드 테두리를 전부 빼고 여백으로 그룹을 나눠", "헤드라인의
  썸네일을 없애고 텍스트만"
- "이 부분이 너무 빽빽해 — 요소를 줄여줘" 처럼 덜어내는 방향을 자주.
- 라이언 캐릭터가 어색하면: "라이언을 더 단순하고 친근하게, 미니멀 라인 일러스트로"

## ④ 출력 후 — Claude Code가 하는 일

1. 마음에 드는 결과를 **HTML/CSS export** 또는 **Figma 복붙** 중 편한 형태로 저장
2. 그 파일/링크를 Claude Code에 전달
3. Claude Code가 `web/`(Next.js) 코드로 통합 — Figma면 MCP로 읽고, HTML이면 직접 변환
4. A/B 중 방향 결정 → 확정안을 SSoT(Figma)에 반영
